# اختبارات التكامل الشامل (e2e)

الآلي منها يعمل بلا متصفح ويشغّله CI. والحي يفتح متصفحًا حقيقيًا، فيتبع «الاختبارات الحية» في [دليل المطوّرين](../../docs/development.md#الاختبارات-الحية): إذن صاحب المشروع قبل كل جولة، وملفات تعريف اختبار خارج المستودع، ووتيرة بشرية، ولا تحايل.

## الآلي

```bash
command node scripts/run-tests.mjs test/e2e/regression test/e2e/static
```

| المجلد | ما فيه |
| --- | --- |
| `regression/` | انحدار إصلاحي التكامل: القائمة التي يُكتب في حقلها تبقى ظاهرة والشريط مخفي، ورسالة «حُفظ ✓» تحت رأس المحرّر. |
| `static/` | الرسائل من كل المجالات والتشخيص بكل مصادره، والحزمة وتدقيق ملفاتها المشحونة (الأذونات الثلاثة وعامل الحفظ وحده)، والعيّنات العربية عبر الاستيراد والمقارنة، والتعارض والفشل الجزئي ببصمة التخزين. |

وهي ضمن `npm run check:all` وفي CI، لا ضمن `npm test` (`test/unit` وحده).

## الحي

| السكربت | الجلسة | ما يفعله |
| --- | --- | --- |
| `live/list.mjs` | مؤتمتة | بندا القائمة الثابتة اللذان لا يحتاجان جسم الترجمة: «بلا ترجمة» و«بإعلان». |
| `live/find-live.mjs` | مؤتمتة بملف مستقل بلا الإضافة | يختار «بثًا مسجّلًا» بمسار إنجليزي للقائمة الثابتة. |
| `live/v2/find-long.mjs` | مؤتمتة بلا الإضافة | يختار فيديو طويلًا (2000 مقطع فأكثر). |
| `live/v2/upgrade.mjs` | مؤتمتة | الترقية من حزمة `tj-v1` إلى الحالية على ملف التعريف نفسه، بلا فقد. |
| `live/v2/ask.mjs` | مؤتمتة **أمامية** | «اسأل عن مكان الحفظ» مرتين، ويضغط صاحب المشروع «حفظ» في حوار النظام. |
| `live/v2/rollback.mjs` | مؤتمتة | `tj-v1` ← الحالية ← `tj-v1` يقرأ ويكتب ← الحالية تصالح دون فقد. |
| `live/v2/downgrade.mjs` | مؤتمتة | الرجوع إلى الإصدار الأول ببيانات حقيقية. |
| `live/v2/assemble.mjs` | — | تجميع ترجمة النموذج: النص منه، والأرقام والتوقيت من الأصل حرفيًا. |

**لماذا لا يُؤتمت الاستخراج:** منفذ التصحيح وحده (`--remote-debugging-port`) يجعل `navigator.webdriver=true` في كل صفحة، فيعيد يوتيوب جسم الترجمة فارغًا تحت أي تحكم، ولا تُخفى علامة الأتمتة لأن ذلك تحايل. فالاستخراج الحقيقي بجلسة يدوية (`test/live/aa5/hand.mjs`)، والدورة الكاملة بعده في `test/live/stores/t3.mjs`.

النتائج في `test-results/live/` (متجاهَل في Git)، والملفات المتغيرة خارج المستودع في `~/Library/Application Support/Tarjuman-test/` أو في `TJ_PROFILE_ROOT`.

## العيّنات العربية الحقيقية (`fixtures/`)

ترجمات نموذج ذكاء اصطناعي خارجي للملفات الإنجليزية التي تصدّرها الإضافة من عيّنتي `test/fixtures/json3/` الحقيقيتين، حُفظت بإذن صاحب المشروع.

| الملف | المقاطع | مصدره |
| --- | --- | --- |
| `iG9CE55wbtY.en.manual.normal.ar.srt` | 427 | محاضرة TED، الوضع العادي (Sonnet). |
| `iG9CE55wbtY.en.manual.normal.haiku.ar.srt` | 427 | المحاضرة نفسها بنموذج آخر (Haiku)، لاختبار ترجمتين في خانتين. |
| `Y9rkKtK1b44.en.asr.long.ar.srt` | 729 | محاضرة ميدواي التلقائية، وضع «مقاطع أطول». |
| `Y9rkKtK1b44.en.asr.normal.ar.srt` | 1,056 | ميدواي بالوضع العادي. فيه أربعة مقاطع بلا حرف عربي كما أعادها النموذج (180 و244 و439 و593). |

- **التعليمات:** نص الملحق أ في [المواصفة](../../docs/product-spec.md) معبّأً حرفيًا.
- **البنية:** الأرقام وسطور التوقيت منسوخة من الأصل حرفيًا (`live/v2/assemble.mjs`)، والنص وحده من النموذج. وأصلا ميدواي ناتج ما قبل ع-٣ (قبل أن يقطع المحوّل مجموعة ASR لا تتسع في سطرين)، مجمّدان في [`test/fixtures/export/`](../fixtures/export/README.md) بملفي `before-e03`، وبهما تُقارن الترجمتان لا بتحويل اليوم.
- **العلامات غير الكلامية:** بقوسين معقوفين كما تطلب التعليمات، مثل [ضحك] و[تصفيق].
- **الفحص:** UTF-8 بلا BOM، ولا رابط ولا رمز (`static/arabic-fixtures.test.js`)، والاستيراد يطابق بصمة التصدير نفسه.
