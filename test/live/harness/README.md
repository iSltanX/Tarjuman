# حزام الاختبار الحي

أساس كل الاختبارات الحية. القواعد في «الاختبارات الحية» من [دليل المطوّرين](../../../docs/development.md#الاختبارات-الحية): إذن صاحب المشروع قبل فتح أي متصفح، وملف تعريف اختبار منفصل خارج المستودع، ووتيرة بشرية، ولا تحايل على أي تحدٍّ.

| الملف | ما فيه |
| --- | --- |
| `browser.mjs` | تشغيل Brave أو Chrome بملف اختبار (`~/Library/Application Support/Tarjuman-test/<profile>`) عبر CDP بالأنبوب، وتحميل الإضافة بـ`Extensions.loadUnpacked`، وصنف `Page`. |
| `cdp.mjs` | عميل CDP بلا اعتماديات (أنبوب أو WebSocket). |
| `extension.mjs` | فتح صفحات الإضافة في تبويب أمامي أو خلفي، وانتظار تبويب تفتحه الإضافة، وجمع أخطاء الإضافة وحدها، والوضع الداكن، ولقطة الصفحة كاملة. |
| `youtube.mjs` | أدوات يوتيوب للحزام فقط: انتظار المشغّل، والضغط على CC كما يفعل المستخدم، والقفز، والمقترحات (`relatedIds` بلا الفيديو الحالي ولا رابط مخفي، و`clickRelated` يرمي إن لم يحدث الانتقال). |
| `netlog.mjs` | سجل شبكة منقّى: عدّادات ومصدر المستدعي، ولا رابط ولا رأس ولا رمز. |
| `smoke.mjs` | دخان الإضافة المبنية: سكربت المحتوى، ونقاط التركيب («مركّبة» شرط النجاح، ف8)، ورد نافذة الأيقونة، وانعكاس التخزين في المشغّل، والصفحات الأربع، والأخطاء، وتحذيرات التثبيت، والشبكة. |
| `youtube-shapes.mjs` | «هل تغيّر يوتيوب؟» (`npm run youtube:shapes`، ف8): أشكال بلا قيم لما يعتمد عليه ترجمان في صفحة يوتيوب (`WATCHED`: `SELECTORS` وزمن المشغّل)، بلا الإضافة، مقارنةً بخط الأساس `test/fixtures/youtube/shapes-baseline.json`، والفروق وصف السجل؛ و`--update` لخط أساس جديد. الانتقال إلى مقترح شرطها: إن لم يحدث فعلًا خرجت بالرمز 1 بلا كتابة. منطقها في `scripts/youtube-shapes.mjs`. |

```bash
command npm run build
```

```bash
command node test/live/harness/smoke.mjs --browser brave
```

- النتائج في `test-results/live/P2/<المتصفح>` (متجاهَل في Git)، و`--out <مجلد>` يغيّرها.
- `--gallery <مجلد بناء تطوير>` يضيف لقطات معرض المكوّنات (`npm run build:dev -- --out <مجلد>`).
- `--headed` يُظهر النافذة؛ الافتراضي بلا نافذة.
- تحت الأتمتة (`navigator.webdriver=true`) تعيد يوتيوب جسم الترجمة فارغًا (P1)، فما يعتمد على الالتقاط نفسه يحتاج جلسة غير مؤتمتة؛ والدخان لا يعتمد عليه.
- بناء التطوير (`npm run build:dev`) يكشف في العالم المعزول `globalThis.__tarjuman = { controller, extractor, store, mounted }` للسيناريوهات الحية؛ بناء الإنتاج يحذفه ويفشل إن بقي.
