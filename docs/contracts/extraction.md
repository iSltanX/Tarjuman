# عقد الاستخراج (مسودة — تحدّثها P1 بما ثبت حيًا)

> **لم يُثبت شيء من هذا في متصفح حي بعد.** هذه المسودة تحوّل [المواصفة §٨](../product-spec.md) إلى قواعد قابلة للاختبار. تكتب P1 تحت كل قاعدة ما ثبت فعلًا ودليله، وتثبّت P2 الصيغة النهائية.

## الطريقة

الالتقاط السلبي: سكربت في `MAIN` world عند `document_start` يقرأ نسخة من استجابة `/api/timedtext` التي طلبها مشغّل يوتيوب نفسه بعد أن فعّل المستخدم `CC`، **دون أي طلب جديد**.

## الرسالة من MAIN إلى ISOLATED

```js
{ source: "tarjuman", v: 1, kind: "timedtext",
  videoId, lang, trackKind: "manual" | "asr", hasTlang: boolean, format: "json3" | "srv3" | "other",
  status: 200, bodyLength, body }   // لا رابط ولا رأس ولا رمز
```

- تُستخرج المعاملات `v` و`lang` و`kind` و`caps` و`fmt` ووجود `tlang` من الرابط داخل MAIN، ثم يُسقط الرابط فورًا.
- اتجاه واحد: لا يقبل سكربت المحتوى أي أمر من الصفحة، ويتحقق من `event.source === window` ومن الحقل `source`، ويعامل `body` بيانات غير موثوقة.

## قواعد القبول

| القاعدة | الرفض ورمزه |
| --- | --- |
| `videoId` يساوي الفيديو المعروض الآن | `EX_WRONG_VIDEO` — «الترجمة الملتقطة تخص فيديو آخر، فتم تجاهلها.» |
| `lang` يبدأ بـ`en` | `EX_NOT_ENGLISH` |
| لا `tlang` | `EX_TRANSLATED_TRACK` — «المختار ترجمة آلية من يوتيوب، اختر English الأصلية.» |
| الجسم غير فارغ ويُحلَّل وفيه أحداث نصية | `EX_EMPTY_BODY` — «تعذّر استخراج الترجمة (استجابة فارغة)…» |
| الصيغة مدعومة | `EX_UNSUPPORTED_FORMAT` |
| الثوابت الستة تنجح | `EX_INVARIANT_FAILED` — «أوقفنا التصدير: النص الناتج لا يطابق المصدر.» |
| آخر توقيت ≥ نسبة الاكتمال من مدة الفيديو | تحذير `EX_MAYBE_INCOMPLETE` لا رفض |
| ليس بثًا جاريًا | `EX_LIVE` |

الذاكرة مفهرسة بـ`videoId`، وتُفرَّغ من غير الفيديو الحالي عند التنقل، فلا يصدَّر إلا مسار الفيديو المعروض.

## الثوابت الستة (من تقرير كلود §٤.٣)

1. تطابق الكلمات بعد إزالة التكرار الحرفي فقط (تطبيع NFC والمسافات، دون حذف ترقيم أو تغيير حالة).
2. لا تداخل: `start < end ≤ next.start`.
3. لا مقاطع فارغة.
4. رتابة أزمنة البداية.
5. الحدود: `start ≥ 0`، وآخر `end ≤ duration + 2s`.
6. إعادة التحليل تعطي العدد والنص نفسيهما.

## الممنوعات

- إعادة إرسال الطلب أو تعديل `fmt` أو `tlang`، وأي طلب InnerTube أو انتحال عميل، وتوليد رموز.
- تخزين أو تسجيل `pot` أو التواقيع أو الروابط أو ملفات الارتباط، في المخزن أو السجلات أو التشخيص أو العينات.
- التفعيل البرمجي عبر واجهات المشغّل غير الموثقة دون قرار سلطان.

## ما تملؤه P1

لكل بند أعلاه: «ثبت / لم يثبت / تغيّر»، ودليله في `docs/evidence/P1/`، وما ظهر من حالات لم تُتوقع.
