# عقد الأخطاء والرسائل والتشخيص

> **مثبّت في P2 (2026-11-01)، ووسّعته P10 للإصدار الثاني (2026-11-02)، وأُضيفت رموز P11 عند دمج W6 (§٦)، ثم جُمِّد.** الشيفرة `src/core/errors/` و`src/core/diagnostics/`، واختباراتها `test/unit/model/errors.test.js`.

## ١. البنية

كل خطأ أو إشعار **رمز ثابت** يقرؤه الرمز، و**رسالة عربية** للمستخدم تقول ما حدث وما يمكن فعله (R35)، و**تفاصيل تقنية منقّاة** للتشخيص فقط (بلا رابط ولا رمز، 500 محرف حدًا). ولرفض الاستخراج والتحويل **سببٌ** (`reason`) من قائمة مغلقة يحدد موضعه داخل رمزه، وهو وحده ما يعبر منه إلى التشخيص، لا وصفه ولا تفصيله (§٤، وعقد الاستخراج).

```js
import { TjError, messageFor, toErrorInfo, hasCode } from 'src/core/errors/index.js';

throw new TjError('MD_NEGATIVE_TIME', { params: { list: '1، 2' }, detail: 'تقني منقّى', cause });
err.code      // 'MD_NEGATIVE_TIME'
err.message   // «الإزاحة تجعل بعض المقاطع قبل بداية الفيديو: 1، 2. …»
err.toJSON()  // { code, message, detail }
toErrorInfo(anyError)   // TjError كما هو، وغيره TJ_UNEXPECTED بتفاصيل منقّاة
messageFor(code, params) // القوالب {name} تُملأ؛ الرمز المجهول يُعاد كما هو
```

صيغة الرمز `^[A-Z]+_[A-Z0-9_]+$`. والرسالة نص عادي بالعربية الواضحة، والأرقام لاتينية.

## ٤. تقرير التشخيص (R36)

```js
import { createDiagnosticReport, formatDiagnosticReport } from 'src/core/diagnostics/report.js';
createDiagnosticReport({ version: '0.2.0', browser: 'Brave 1.98', sections: { store: {...}, extract: extractor.diagnostics() } })
```

- **يتضمن:** الإصدار، والمتصفح، ورموز الأخطاء، والأحجام والأعداد.
- **سبب الرفض وعدّادات المسار (الفكرة ٤-ب، ح-38، بعد 2.2.0):** في تشخيص المستخرج لكل رفض `reason` من `REASONS` (`src/core/convert/reasons.js`، والمجهول `other`)، ولكل مسار `reason` و`rolling` (`eventIndex` و`repeatedWords` أرقامًا، و`basis` من `time` و`pattern`) و`stats` (إحصاءات التحليل) و`converter` (عدّادات المحوّل والتكرار وإعادة الترتيب والقص). تُنتقى حقلًا حقلًا أرقامًا وقيمًا منطقية، فلا يُنسخ كائن الخطأ ولا `message` ولا `detail`. وعدّاد كلمات المحوّل التلقائي `wordCount` لا `words`، لأن `words` من المفاتيح المستبعدة أدناه فكان يظهر «[مستبعد]» (اختبار: `findSecrets` فارغ ولا «[مستبعد]» في المسارات والرفض).
- **`EX_UNSUPPORTED_FORMAT` تسمّي الصيغة** (الإنذار المبكر، الفكرة ٤): رسالتها دالّة بمعامل `format`، تذكر اسم الصيغة معزولًا بين قوسين إن كان رمز صيغة (`srv3` أو `vtt` من آخر رفض)، وبلا معامل صالح هي النص السابق حرفيًا.
- **لا يتضمن أبدًا:** روابط، أو رموز جلسة، أو ملفات ارتباط، أو نص ترجمة أو عنوان فيديو: المفاتيح `text` و`texts` و`cues` و`body` و`srt` و`original` و`current` و`title` و`fileName` و`lines` و`words` و`detail` و`lastDetail` و`videoId` و`name` تُستبدل بـ«[مستبعد]» (الأربعة الأخيرة من C7، §١١)، ثم يمر الباقي بـ`sanitizeDeep` (اختبار).
- `src/core/diagnostics/sanitize.js` (من P1) هو المنقّي الوحيد، ويستعمله الفحص الآلي `check:secrets` على العينات والأدلة.
- لا `console.*` في `src` (فحص ثابت): الأخطاء رموز في الحالة وتقرير التشخيص.

## ٥. الإصدار الثاني (P10)

- **الحفظ** (`SV_`، عقد الواجهات §١٣): `SV_FALLBACK_BLOB` إشعار حين تعذّرت واجهة التنزيلات فنُزّل الملف بالطريقة الحالية (مجلد التنزيلات وإعداد المتصفح)، و`SV_BAD_FILE` اسم أو امتداد غير مقبول، و`SV_TOO_LARGE` فوق حد القناة، و`SV_BAD_FOLDER` اسم مجلد فرعي غير صالح، و`SV_CANCELLED` ألغى المستخدم حوار الحفظ، و`SV_FAILED` غير ذلك. و`SV_UNSETTLED` (تدقيق 7a66f91، C4): صدر معرّف التنزيل وتعذّر الاستعلام عن نتيجته أو غاب عنصره، فلا بديل Blob كي لا يتكرر الملف.
- **الخانات والسابقة** (`ST_`): `ST_SLOT_EMPTY` تفعيل خانة فارغة أو تعديلها، و`ST_NO_PREVIOUS` استعادة بلا سابقة، و`ST_PREVIOUS_SAVED` إشعار «حُفظت الترجمة المستبدلة نسخةً سابقة…». والاستبدال بلا تأكيد يبقى `ST_ARABIC_EXISTS`.
- **القفز** (`TJ_`): `TJ_WRONG_VIDEO` التبويب يعرض فيديو غير المطلوب، و`TJ_SEEK_FAILED` تعذّر تغيير الزمن (لا مشغّل بعد).
- **النسخة الاحتياطية** (`BK_`): المجال مسجّل ببادئته وبلا رسائل حتى P13. محتوى النسخة لا يدخل التشخيص أبدًا: الأعداد والرموز وحدها.
- **تشخيص الصفحة** (عقد الرسائل §٦) يضيف قسم `page` من أعداد المتحكم والمستخرج وحالة التركيب ورموزها.
