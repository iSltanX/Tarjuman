# عقد نموذج البيانات

> **مثبّت في P2 (2026-11-01)، ووسّعته P10 للإصدار الثاني (2026-11-02) ثم جُمِّد.** الشيفرة المرجعية `src/core/model/` بأنواع JSDoc ومدققات صارمة، وعينات مطابقة في `test/helpers/fixtures.js` و`test/helpers/fixtures-v2.js` تجتاز المدققات (`test/unit/model/`). تغيير أي بنية هنا تغيير عقد: المرحلة متعطلة حتى يحسمه المنسّق على `main`.
>
> **§٠–§٩ أشكال الإصدار الأول، وتبقى حرفيًا** (لا حقل يُضاف ولا يُحذف، ولا رفع لـ`schema`): حزمة `tj-v1` تقرأ وتكتب السجل والفهرس والإعدادات بمدققاتها الصارمة. **§١٠–§١٦ إضافات الإصدار الثاني** في مفاتيح جديدة لا يعرفها الأول (عقد التخزين §٧).

## ٠. قواعد عامة

- **الأزمنة** أعداد صحيحة بالملي ثانية من 0 إلى 360,000,000 (100 ساعة). **التواريخ** نصوص ISO بتوقيت UTC مثل `2026-11-01T12:00:00.000Z`.
- **النص خام**: لا HTML ولا وسوم؛ الأسطر بـ`\n`، ولا محرف `\u0000`. العرض بـ`textContent` وحده.
- **المدققات صارمة**: المفتاح المفقود أو غير المعروف فشل، فلا تضيف مرحلة حقلًا دون تغيير عقد. كل مدقق يعيد `{ ok: true }` أو `{ ok: false, path, reason }` ولا يرمي، و`assertValid` يحوّل الفشل إلى `MD_INVALID`.
- **لا يُخزَّن أبدًا**: جسم `json3` الخام، وأي رابط أو رأس أو `pot` أو توقيع أو ملف ارتباط (عقد الاستخراج).
- **الحدود** (`LIMITS`): 50,000 مقطع، و5,000 محرف للنص، و500 للعنوان، و255 لاسم الملف، و8 مسارات إنجليزية، و10 بصمات، و50 ملاحظة بطول 500.

## ١. المعرّفات والمفاتيح — `src/core/model/ids.js`

| الاسم | الصيغة | مثال |
| --- | --- | --- |

## ٢. المقطع — `cue.js`

```js
Cue = { n: 1, startMs: 27103, endMs: 29678, text: "سطر أول\nسطر ثانٍ" }   // أزمنة أول مقطع في عينة P1 اليدوية
CueTime = { n, startMs, endMs }                                       // في البصمة: بلا نص
```

- `n` عدد صحيح موجب، ويُحفظ **كما ورد** في الملف العربي (الترقيم غير المتسلسل يبلّغ عنه المقارن ولا يُصلح). الكاتب يرقّم من 1 عند التصدير.
- **التحقق بنيوي فقط:** مشكلات التوقيت يعرضها المحرّر، لا خطأ نموذج؛ فيقبل التخزين ملفًا مستوردًا فيه هذه المشكلات ليعرضها. نهاية قبل بداية خطأ يمنع الحفظ من المحرّر والتصدير. والتداخل تحذير لا يمنع الحفظ، لكنه يمنع تصدير SRT كما يمنعه المقطع بلا نص، لأن كاتب SRT يرفضهما (`EX_TIMING_INVALID` و`EX_EMPTY_TEXT`) ورسالته تحيل إلى المحرّر (قرار سلطان في W4: «يبقى المنع»).
- النص الفارغ مقبول بنيويًا (مقطع لم يترجمه النموذج يبلّغ عنه المقارن في `empty`).

## ٣. المسار الإنجليزي — `tracks.js`

```js
EnglishTrack = {
  key: "en|manual", lang: "en", kind: "manual" | "asr",
  capturedAt: "2026-11-01T10:47:42.000Z", source: "capture",
  cues: Cue[]            // الوضع «عادي» كما أخرجه المحوّل؛ مقطع واحد على الأقل
}
```

- `kind` من `kind=asr` في طلب المشغّل وحده (عقد الاستخراج). `source` له قيمة واحدة الآن: `capture`.
- يُحفظ عند تنزيل SRT إنجليزي (مع بصمته)، أو مرجعًا عند استيراد عربي إن كان ملتقطًا؛ ولا يُحفظ كل التقاط تلقائيًا.
- **الحجم الواقعي** (عينات P1): اليدوي 427 مقطعًا ≈ 40 ألف محرف JSON، والتلقائي 1,056 مقطعًا ≈ 103 آلاف.

## ٤. البصمة — `tracks.js`

```js
Fingerprint = {
  id: "fp_…", videoId: "iG9CE55wbtY", trackKey: "en|manual", mode: "normal" | "long",
  count: 427, cues: CueTime[],        // ترقيم متسلسل من 1، وcount = cues.length
  textHash: "fnv1a64:…",              // "<خوارزمية>:<hex>"، تختارها P3 وتوسمها
  fileName: "iG9CE55wbtY.en.manual.normal.srt" | null,
  createdAt: "ISO",
  parts: null | [{ index: 1, from: 1, to: 200 }, { index: 2, from: 201, to: 427 }]
}
```

- تُحفظ محليًا ولا تُضمَّن في الملف المصدَّر. بصمة لكل تصدير (لكل وضع ولكل تقسيم).
- `parts` للتقسيم الاحتياطي وحده: جزآن فأكثر، **ترقيم مستمر** يغطي 1..count دون فجوة ولا تداخل (المدقق يفرضه).
- `trackKey` يشير إلى مسار محفوظ في السجل نفسه. حد السجل 10 بصمات، وتسقط الأقدم إلا التي تشير إليها الترجمة العربية.
- البصمة لا تحمل نصًا أبدًا (المدقق يرفض `text`).

## ٥. تقرير المقارنة — `tracks.js`

وصف فقط، لا يعدّل شيئًا. ينتجه المقارن (P4) ويعرضه الشريط (ملخصًا، P6) والمحفوظات (P7) والمحرّر (تفصيلًا، P8).

```js
ComparisonReport = {
  fingerprintId: "fp_…" | null,    // null = لا بصمة للمقارنة («يُعرض الملف كما هو»)
  matched: boolean,                // تطابق العدد والترقيم، ولا نقص ولا زيادة ولا انحراف فوق العتبة
  countSource: 427 | null,         // عدد البصمة؛ null بلا بصمة
  countTarget: 425,                // عدد الملف العربي
  numbering: "same" | "different",
  missing: [57, 58], extra: [],    // أرقام مقاطع
  drift: [{ n: 12, startDeltaMs: 300, endDeltaMs: -200 }],   // العربي − البصمة، فوق العتبة فقط
  empty: [201], noArabic: [88],    // تحذيرات محتوى لا تؤثر في matched
  restoreTimingAvailable: boolean, // true فقط عند تطابق العدد والترقيم
  driftThresholdMs: 100,           // العتبة المستعملة
  notes: ["أُزيلت علامات كتلة النص (``` أو ~~~) المحيطة بالملف."]   // كل تحويل للنص يُذكر هنا
}
```

**التقرير الحاضر** (`currentComparison`، تدقيق 5fedcb9) يحكم بالمحاذاة فلا يحسب الدمج والشطر نقصًا وزيادة وانحرافًا، لكنه لا يجعل `matched` صحيحًا معهما ولو توازن العدد: «مطابق للأصل» يعني الأرقام والتوقيت (تدقيق 7a66f91، C5، U29).

**قيود يفرضها المدقق:** بلا بصمة ← `countSource=null` و`matched=false` و`restoreTimingAvailable=false`. و`restoreTimingAvailable` يعني `countSource = countTarget` و`numbering = same`. و`matched` يعني ذلك وغياب `missing` و`extra` و`drift`.

## ٦. الترجمة العربية وسجل الفيديو — `tracks.js` و`video.js`

```js
ArabicTrack = {
  fileName: "iG9CE55wbtY.ar.srt", importedAt: "ISO",
  original: Cue[],          // الأصل المستورد: لا يتغير إلا باستبدال الملف
  current: Cue[] | null,    // null = مطابقة للأصل؛ وإلا آخر حفظ من المحرّر
  editedAt: "ISO" | null,   // يوجد مع current ويغيب معه
  fingerprintId: "fp_…" | null, comparison: ComparisonReport | null,
  notes: string[]           // ملاحظات الاستيراد (مثل التنظيف)
}

VideoRecord = {
  schema: 1, videoId, title: string | null, durationMs: number | null,
  createdAt: "ISO", updatedAt: "ISO", rev: 1,      // يضبطها التخزين؛ rev يزيد مع كل حفظ
  english: EnglishTrack[],                         // مفاتيح فريدة
  fingerprints: Fingerprint[],
  arabic: ArabicTrack | null,
  view: { displayOffsetMs: 0, displayMode: "ar" | "dual" | "off" }
}
```

- ترجمة عربية فعّالة واحدة لكل فيديو (المواصفة §١١). المعروض `current ?? original` (`arabicCues(record)`).
- `displayOffsetMs` عدد صحيح من **مضاعفات 100** ضمن ±600,000 (عقد التوقيت). `displayMode`: `ar` العربية وحدها، و`dual` العربية فوق الإنجليزية، و`off` إخفاء.
- `arabic.fingerprintId` يشير إلى بصمة محفوظة في السجل نفسه.
- **الحجم الواقعي:** نحو 330 محرفًا لكل مقطع لسجل كامل (مسار إنجليزي وبصمة وعربي أصل وحالي): فيديو بـ1,056 مقطعًا ≈ 354 ألفًا، وبـ2,000 مقطع ≈ 0.7 م.ب (قيس على عينات P1؛ `test/unit/model`).

## ٧. انتقالات السجل — `transitions.js`

دوال نقية يستعملها المتحكم (P6 عبره) والمحفوظات (P7) والمحرّر (P8)، فتبقى القواعد واحدة أينما حُفظ السجل. كل دالة تعيد سجلًا جديدًا، والتخزين يتحقق ويضبط `rev` والتواريخ.

| الدالة | متى | ما تفعله | ما لا تمسه |
| --- | --- | --- | --- |
| `withExport(rec, { videoId, title, durationMs, englishTrack, fingerprint })` | بعد تنزيل SRT إنجليزي | تحفظ المسار (أحدث التقاط لمفتاحه) وتضيف البصمة؛ وعند امتلاء حد المسارات يُسقط أقدم مسار لا تشير إليه بصمة | العربية والإزاحة |
| `withArabicImport(rec, { videoId, fileName, cues, comparison, fingerprintId, notes, englishTrack, displayModeDefault }, now, { replace })` | استيراد أو استبدال | الملف يصبح الأصل المستورد، و**الإزاحة صفر دائمًا**، و`off` يعود إلى الافتراضي، والمسار الملتقط يُضاف مرجعًا إن لم يكن محفوظًا وفي الحد متسع. وجود ترجمة دون `replace` يرمي `ST_ARABIC_EXISTS`. تعيد `{ record, offsetWas, replaced }` | — |
| `withView(rec, { displayOffsetMs?, displayMode? })` | ± ووضع العرض | الإزاحة أو الوضع | أي توقيت محفوظ |
| `withArabicEdit(rec, { cues, displayOffsetMs? })` | «حفظ» المحرّر | `current` = المقاطع، و`editedAt` الآن، والإزاحة إن مُرِّرت في الخطوة نفسها | `original` |
| `withOriginalRestored(rec)` | «استعادة الأصل» | `current = null` | `original` |
| `withoutArabic(rec)` | حذف العربية وحدها | `arabic = null` والإزاحة صفر | المسار الإنجليزي والبصمات |

## ٨. الإعدادات — `settings.js`

```js
Settings = {
  schema: 1,
  offsetStepMs: 500,                       // 100..10000 من مضاعفات 100 (الخطوة 0.5 / 1 / مخصصة)
  displayModeDefault: "ar" | "dual",
  appearance: {
    font: "almarai" | "noto-sans-arabic" | "tajawal" | "markazi",   // خط الترجمة فوق الفيديو وحدها

    background: "none" | "soft" | "solid", position: "bottom" | "raised" | "top"
  },
  export: { modeDefault: "normal" | "long", splitThreshold: 200 },   // العتبة 50..2000
  thresholds: { driftMs: 100, completeness: 0.85 }                                        // 10..5000 و0.5..1

```

الافتراضيات: الخطوة 500، والعربية وحدها، والخط `almarai` والحجم 100، والخلفية `soft`، والموضع `bottom`، والتصدير «عادي» (Q4)، والتقسيم عند 200، والانحراف 100ms، والاكتمال 85% (Q6). التعليمات لا تُعرض في الواجهة أبدًا، فلا إعداد لها (حُذف `export.showInstructions` في «تهيئة W4»). والحجم نسبة فوق الحجم النسبي لارتفاع المشغّل؛ والمقاسات القديمة قبل W4 (`appearance.size`) تحوّلها القراءة المتسامحة وحدها: `s` إلى 85، و`m` إلى 100، و`l` إلى 120، و`xl` إلى 145، والنسبة الصالحة تسبقها. الخطوط وملفاتها في `src/ui/subtitle-fonts.js` (عقد الواجهات §٩). **القراءة متسامحة** (`normalizeSettings`: كل حقل تالف يعود افتراضيه دون فقد البقية)، و**الكتابة صارمة** (`validateSettings`)، والتعديل الجزئي يُدمج حتى مستوى المجموعة (`mergeSettings`).

## ١٠. الترجمات الثلاث والحزمة — `slots.js` و`bundle.js` (الإصدار الثاني)

حتى ثلاث ترجمات لكل فيديو في **خانات** مرقّمة 1 2 3 (R43)، واحدة منها **نشطة**. **النشطة تبقى في السجل نفسه** (`record.arabic` وإزاحتها `record.view.displayOffsetMs`)، فتراها حزمة `tj-v1` وتعدّلها كما اعتادت، وتعمل الواجهات القائمة دون تعديل. والأخريان والنسخة السابقة والعلامات بجانب السجل (عقد التخزين §٧).

**الحزمة** شكل منطقي يجمع السجل وتوابعه، تقرؤه وتكتبه واجهة التخزين (`getBundle` و`updateBundle`)، ولا يُخزَّن بهذا الشكل:

```js
Bundle = {
  videoId,
  record: VideoRecord,                 // كما في §٦ حرفيًا؛ النشطة في arabic وإزاحتها في view.displayOffsetMs
  active: 1 | 2 | 3 | null,            // null ⇔ لا ترجمة أصلًا
  slots: [SlotView, SlotView, SlotView],   // بالترتيب n = 1، 2، 3
  previous: Previous | null            // §١١
}
SlotView = {
  n: 1 | 2 | 3,
  name: string | null,                 // الاسم المختصر: 1..24 محرفًا بعد التشذيب، سطر واحد؛ للخانة الممتلئة وحدها
  track: ArabicTrack | null,           // §٦ بشكله نفسه: نصها وأصلها وتعديلاتها ومرجعها (fingerprintId وcomparison)
  offsetMs: number,                    // إزاحة عرضها (عقد التوقيت)؛ 0 للفارغة
  marks: Mark[],                       // §١٢، للممتلئة وحدها
  position: Position | null            // آخر موضع (§١٢)
}
```

**ثوابت يفرضها المدقق** (`validateBundle`):

- `active === null` ⇔ `record.arabic === null` ⇔ الخانات الثلاث فارغة. فإن وُجدت ترجمة فواحدة نشطة دائمًا.
- للنشطة: `slots[active-1].track` و`offsetMs` نسخة من `record.arabic` و`record.view.displayOffsetMs`. **السجل هو المرجع**: الانتقالات تغيّره، و`syncActive` يعيد ملء الخانة منه.
- الخانة الفارغة: `name = null` و`offsetMs = 0` و`marks = []` و`position = null`.
- `fingerprintId` الخانة غير النشطة أو النسخة السابقة يشير إلى بصمة في `record.fingerprints` أو يُقرأ `null` (البصمة التي أسقطها حد البصمات تفقد مرجعيتها، فتُعرض «بلا مرجع» حتى يُختار غيرها). و`comparison` يبقى كما حُفظ وصفًا للملف كما رُفع، ويبقى مع `fingerprintId: null` ولو أشار إلى بصمة غائبة (لا يُمسح في الإسقاط ولا في الاستعادة، تدقيق V2، U-011). والتحذيرات الحاضرة (مُلخّص الفهرس، و`warned` في ملخص الفرز، وحالة المتحكم ورد الحالة، ولوحتا المحرّر) تُشتق ولا تُخزَّن: `trackComparison(track, fingerprints)` في `src/core/compare/current.js` للنسخة المعروضة بمحاذاتها الزمنية بالبصمة (وبثقة منخفضة حكم الرقم)، فلا حالة تتقادم بعد الاستكمال أو التحرير (R46؛ تدقيق 5fedcb9).
- الحد: 5,000 علامة لكل خانة (`LIMITS.maxMarks`).

**نموذج الخانة للواجهة** (`slotModels(bundle)`، يطابق `SlotModel` في `src/ui/components.js`): `{ n, filled, active, name }` لكل خانة، ومعها `edited` و`cueCount` للعرض.

## ١١. النسخة السابقة — `slots.js`

نسخة استرجاع **واحدة** لكل فيديو، تُحفظ تلقائيًا في الكتابة نفسها قبل **استبدال** أي ترجمة أيًّا كان مساره: المتحكم، أو الصفحات القائمة عبر `updateVideo`، أو الانتقالات الجديدة (R44). والاستبدال ملف جديد فوق خانة ممتلئة: يتغير الأصل المستورد (`original`، ولا يتغير إلا به) أو تاريخ استيراده أو اسم ملفه. ليست ترجمة رابعة: لا تظهر في 1 2 3 ولا تُفعَّل.

```js
Previous = { from: 1 | 2 | 3, savedAt: "ISO", track: ArabicTrack, offsetMs: number }
```

- الاستبدال التالي يكتب فوقها (واحدة فقط). والحذف والتعديل و«استعادة الأصل» ليست استبدالًا فلا تحفظها.
- **الاستعادة تبديل قابل للعكس** (`withPreviousRestored`): محتوى الخانة `from` الحالي يصبح السابقة، والسابقة تعود إلى خانتها؛ فإن كانت الخانة فارغة عادت إليها وصارت السابقة `null`. واستعادة ثانية تعكس الأولى.
- تُحذف مع الفيديو، ولا يحذفها حذف خانتها (تبقى قابلة للاستعادة إليها).
- **ما يستبدله الإصدار الأول أو يحذفه لا تُحفظ له سابقة**: الأول لا يعرفها (عقد التخزين §٨).

## ١٢. العلامات وآخر موضع — `marks.js`

علامات المراجعة «أعود إليه» (`todo`) و«راجعته» (`done`) لكل ترجمة (R53)، مرتبطة بالمقطع ارتباطًا متحققًا لا برقمه وحده:

```js
Mark = { n: 12, startMs: 27103, textHash: "9f3a01c2", kind: "todo" | "done", at: "ISO" }
Position = { n: 312, startMs: 1803000, at: "ISO" }        // آخر موضع لكل ترجمة
```

- `textHash` = `cueTextHash(text)`: FNV-1a بـ32 بت للنص بعد التشذيب وطيّ المسافات، بثمانية محارف ست عشرية.
- العلامة لا تحمل نصًا (التشخيص والنسخة الاحتياطية تحملانها بلا نص). علامة واحدة لكل مقطع.
- نوعان مخزَّنان بحسب R53 وبند تقرير المراجعة المثبت (`mark: 'todo' | 'done' | null`). و«تحتاج تحقق» في مواصفة التصميم §١٩.٩ مجموعة عرض في لوحة المراجعة (P14) لا نوع علامة ثالثًا.

## ١٤. تفضيلات الإصدار الثاني — `prefs.js`

في مفتاح `prefs` مستقل لا في `settings`، لأن كتابة الإعدادات من الإصدار الأول (`normalizeSettings` ثم `validateSettings`) تُسقط أي حقل لا تعرفه. القراءة متسامحة لكل حقل (`normalizePrefs`)، والكتابة صارمة (`validatePrefs`)، والدمج حتى مستوى المجموعة (`mergePrefs`).

```js
Prefs = {
  schema: 1,
  glossary: {
    attach: true,                         // «أرفق القاموس بتعليمات الترجمة» حين يوجد
    terms: [{ source: "prompt", target: "موجِّه", note: null }]   // حتى 100 مصطلح
  },
  review: { maxCps: null },               // حد سرعة القراءة (حرف/ث) 5..40، وnull = الافتراضي المعايَر في P11 (Q15)
  saveLocation: { mode: "downloads" | "subfolder" | "ask", folder: "Tarjuman" },  // R65، Q17
  ui: { thumbnails: false, panelEntry: true, panelOpen: false, panelDual: true }   // الوضع العادي (2026-11-03، product-spec §٦.٦)؛ والصور مطفأة منذ و2 (2.2.0)
}
```

- **مصطلح القاموس** (واجهة ربط مثبتة للإصدار الثاني): `{ source: string (1..80), target: string (1..80), note: string | null (≤120) }` بعد التشذيب، سطر واحد بلا محارف تحكم؛ و`source` فريد دون اعتبار لحالة الأحرف. تستهلكه `instructions({ …, glossary })` في P11. القراءة المتسامحة تُسقط المصطلح التالف وحده.
- **مكان الحفظ** (عقد الواجهات §١٣): `folder` اسم مجلد واحد داخل التنزيلات، 1..60 محرفًا، بلا `/ \ : * ? " < > |` ولا محارف تحكم، ولا يبدأ أو ينتهي بنقطة أو مسافة، وليس اسمًا محجوزًا في Windows (`CON` و`NUL` و`COM1`…). الافتراضي «مجلد التنزيلات» يطابق السلوك الحالي.
- **تفضيلات الواجهة `ui`** (قرار سلطان 2026-11-03، [product-spec.md §٦.٦](../product-spec.md)): `thumbnails` صور الفيديو في المحفوظات من خوادم يوتيوب، و`panelEntry` زر لوحة النص المتزامن في صفحات الفيديو، و`panelOpen` اللوحة مفتوحة، و`panelDual` الأصل تحت العربية في اللوحة. كلها منطقية. تفضيلات الجهاز: النسخة الاحتياطية تحملها ولا تستعيدها (`PREFS_GROUPS`)، فتبقى قيم الجهاز المستعيد؛ إلا إطفاء `thumbnails` فيُطبَّق عند الاستعادة ويبقى بعد «مسح كل البيانات» (تدقيق 7a66f91، U05، قرار Q10؛ عقد backup §٦ وstorage §٣). والتفضيلات المحفوظة بلا `ui` تُقرأ بافتراضيها.
- الافتراضيات `DEFAULT_PREFS`: قاموس فارغ مرفق، و`maxCps: null`، و`downloads` و`Tarjuman`، و`ui` بزر اللوحة مفعّلًا واللوحة مغلقة ومع الأصل، وصور الفيديو **مطفأة** (و2، 2026-11-10). التفضيلات تُكتب كاملة عند أي تغيير، فقيمة الصور صريحة عند من غيّر أي تفضيل؛ ومن لم تُكتب تفضيلاته قط تُكتب حاله «ظاهرة» صراحةً عند حدث التحديث في Chromium (`installThumbsPin` في `src/background/thumbs-pin.js`، حين يغيب `prefs` أو تغيب قيمة `ui.thumbnails`). بلا رفع لمخطط التخزين.

## ١٥. ملخص الفرز — `bundle.js`

صغير، في رأس الحزمة (عقد التخزين §٧)، فتفرز المحفوظات دون قراءة الترجمات (R46). يُحسب عند كل كتابة من البيانات نفسها، فلا حالة مكررة تتقادم:

```js
SortSummary = {
  filled: 0..3,                     // الخانات الممتلئة
  edited: 0..3,                     // الممتلئة ذات النسخة الحالية (معدّلة)
  warned: 0..3,                     // الممتلئة التي في مقارنتها نقص أو زيادة أو انحراف (الفحص الآلي)
  marks: { todo: number, done: number }   // كل الخانات («تحتاج مراجعة» = todo > 0؛ المراجعة البشرية منفصلة عن الآلي)
}
```

و«بانتظار الترجمة» و«مترجمة» من مُلخّص الفهرس (§٩: `english` و`arabic`). سجل الإصدار الأول بلا رأس ملخصه من سجله: `filled` 1 أو 0، و`edited` و`warned` للنشطة، ولا علامات.

## ١٧. اللغات — 2.0.0 (AA1، حرية اللغات)

الأسماء التاريخية باقية في السجل المخزَّن لأن الإصدار الأول و1.1.0 يقرآنه بها (`english` للمسارات المستخرجة، و`arabic` للترجمة النشطة، و`noArabic` في تقرير المقارنة). والجديد في الذاكرة، ويُسقط في التخزين (عقد storage §١٣):

- **المسار المستخرج (`SourceTrack`):** `EnglishTrack` بأي لغة (`isSourceLang`: BCP-47 حتى 35 محرفًا)، ومعه `via` اختياريًا للمسار الذي ترجمه يوتيوب آليًا: لغة المسار الذي تُرجم عنه. المفتاح `lang|kind` للأصلي و`lang|kind|via` للمترجم آليًا (`trackKey`، `parseTrackKey`)، و`parseV1TrackKey` لما يقرؤه السجل المخزَّن (إنجليزي أصلي وحده). المدققان: `validateSourceTrack` (الذاكرة) و`validateEnglishTrack` (المخزَّن، كما كان).
- **الترجمة:** حقل `lang` اختياري في الذاكرة: رمز لغتها أو `null` «غير محددة»، وغيابه (ما حُفظ قبل 2.0.0) بمعنى `null`. يُحمل مع الترجمة في كل انتقال. ويأتي من اختيار المستخدم عند الرفع، أو من رمز صريح في اسم الملف قبل `.srt` مباشرة يوافق نصُّ الملف نص كتابته (`langFromFileName` بفحص `textFitsLang`، ع-٨)، فلا تصير كلمة من الاسم لغةً بكتابة أخرى (`let.it.be.srt` بنص لاتيني، و`what.it.is.srt` بنص عربي). ولا يُخمَّن من النص، فالكتابة الواحدة لا تميّز لغتين: `what.it.is.srt` بنص إنجليزي يبقى `is`.
- **المدققات بوضعين:** `validateVideoRecord(r, { stored })` و`validateArabicTrack(a, path, { stored })` و`validateFingerprint(f, path, { stored })` و`validateAltSlot`/`validatePrevious`: المخزَّن (الافتراضي في التخزين) كما يقرؤه 1.1.0 حرفيًا، والذاكرة (`stored: false`) بالحقول الجديدة. و`validateBundle` بوضع الذاكرة.
- **«غير مترجم» بلغة الترجمة:** `untranslatedTest(target, source)`: مقطع بحروف ليس فيها حرف من نص لغة الترجمة، حين يُعرف نصها ويختلف عن نص لغة المسار؛ وإلا لا فحص. يملأ `noArabic` باسمه التاريخي في المقارن والمقارنة الحاضرة والاستكمال والمراجعة.
- **`LangPrefs`** (`model/lang-prefs.js`، المفتاح `langPrefs`):

```js
LangPrefs = {
  schema: 1,
  pair: { from: 'auto' | string, to: string | null },   // الزوج الافتراضي؛ to الافتراضية 'ar' قيمةً يغيّرها المستخدم
  remember: boolean,                                    // تذكّر آخر زوج
  recent: string[],                                     // اللغات الأخيرة، حتى 8، بلا تكرار
  videos: Record<videoId, { from: string | null, to: string | null }>,  // الزوج لكل فيديو، حتى 200
  order: videoId[],                                     // ترتيب الاختيار، الأحدث آخرًا؛ مجموعته تطابق مفاتيح videos تمامًا (تدقيق V2، U-018)
}
```

**الأحدثية من `order` لا من ترتيب مفاتيح `videos`** (تدقيق V2، U-018): Chromium يرتّب مفاتيح الكائنات المتداخلة عند القراءة، فكان «آخر زوج» خارج صفحة الفيديو والطرد عند حد 200 يتبعان الترتيب الأبجدي. فـ`applyLangPrefs` يقدّم الفيديو المُختار إلى آخر `order` ويُسقط من أوله عند الحد، و`initialPair` يأخذ `videos[order.at(-1)]`. `validateLangPrefs` يشترط `order` وتطابق مجموعته مع مفاتيح `videos`، و`normalizeLangPrefs` (القراءة المتسامحة) يبنيه من مفاتيح `videos` عند غيابه (القيم المخزَّنة قبل الحقل)، ويحترم الموجود الصالح ويُلحق به ما غاب. `videos` بقي كائنًا. **التوافق:** 1.1.0 لا يقرأ المفتاح `langPrefs` أصلًا، والقارئ المتسامح يطبّع الغائب ويُسقط الفائض.

و`initialPair(prefs, { videoId, sourceLang })` (بصيغته في AA3): لفيديو، «من» المحفوظة له وإلا لغة المسار الملتقط أو المنزَّل إن عُرفت بدقة حين يكون الافتراضي «تلقائي» (أو لغة الافتراضي إن كانت لغةً بعينها)، وإلا `null` (قرار سلطان ق٥)؛ و«إلى» المحفوظة له وإلا الافتراضية. وخارج صفحة فيديو الافتراضي، و«من» التلقائي يأخذ «من» آخر زوج لفيديو مع التذكّر. و`fromDetected` حين تكون «من» هي المكتشفة نفسها.

**ما يُكتب حين يتغير الزوج في النافذة (AA3):** `pairPatch(prefs, { videoId, pair, why })` يعيد تعديلًا لـ`applyLangPrefs`: اللغة المختارة تتقدّم في `recent`، وما غيّره المستخدم وحده يُحفظ للفيديو والآخر كما كان أو `null` (فلا تُثبَّت «من» المكتشفة ولا «إلى» الافتراضية؛ مراجعة AA3)، و`pair.to` يصير «إلى» المختارة حين يكون `remember` مفعّلًا (فـ«آخر زوج» هو الافتراضي نفسه). و`pair.from` لا يُكتب من النافذة أبدًا، فلا يُفقد «تلقائي». و`applyLangPrefs` يقبل أيضًا `videos` (أزواج من نسخة احتياطية تُضاف إلى الموجود بترتيب `patch.order` إن مُرِّر وإلا بترتيب مفاتيحه، والأحدث آخرًا عند الحد).

**حذف بيانات الفيديو يزيل زوجه** (تدقيق V2، U-019): `store.deleteVideo` و`updateBundle(id, () => null)` يزيلان `videos[id]` من `langPrefs` بعد حذف الفيديو (كتابة عبر طابور `langPrefs` في الكاتب، وبلا كتابة إن لم يكن له زوج)، فلا يبقى معرّفه محليًا ولا في النسخة الاحتياطية. وحذف ترجمة واحدة يُبقي الزوج، واختيارات ما قبل الحفظ لا تُكنس تلقائيًا.

**لغة ترجمة محفوظة (AA3):** `withSlotLang(bundle, n, lang, now)` يحدد لغة ترجمة خانة ممتلئة أو يغيّرها (رمز أو `null`)، بلا مساس بنصها وتوقيتها ومقارنتها وتاريخ تعديلها؛ والكاتب يقدّم المراجعة وحدها (`updateBundle` بـ`touch: false`)، فيرى كل سياق التغيير ولا يتبدل ترتيب المحفوظات. واللغة نفسها لا تغيّر شيئًا. الخانة الفارغة `ST_SLOT_EMPTY`، والرمز التالف `MD_INVALID`. ويُكتب في المرافق `lang:` وحده، فيبقى السجل كما يقرؤه 1.1.0.

**الزوج اللغوي للعرض (AA3، `model/pair.js`):** `sourceOf(record, track)` مسار الأصل لترجمة (مسار بصمتها، وإلا الأول بترتيب قائمة التحميل)، و`recordPair(record)` و`slotPairs(bundle)` بـ`{ from, to, via }` لكل ترجمة؛ للمحفوظات والنافذة والمحرّر.
