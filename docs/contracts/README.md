# العقود المشتركة

> **مثبّتة في P2 (2026-11-01)، ووسّعتها P10 للإصدار الثاني (2026-11-02) ثم جُمِّدت ببوابة W6:** لا تتغير أثناء موجة متوازية، والحاجة إلى تغيير عقد تجعل المرحلة متعطلة حتى يحسمه المنسّق على `main`. كل عقد يشير إلى شيفرته المرجعية واختباراتها، والتوقيعات فيه مطابقة لها.

| العقد | ما يحدده | الشيفرة المرجعية |
| --- | --- | --- |
| [`data-model.md`](data-model.md) | المقطع، والمسار الإنجليزي، والبصمة، وتقرير المقارنة، والترجمة العربية، وسجل الفيديو، والانتقالات، والإعدادات، ومُلخّص الفهرس؛ وفي الثاني: الترجمات الثلاث والحزمة، والنسخة السابقة، والعلامات وحلّ ارتباطها، وانتقالات الحزمة، والتفضيلات، وملخص الفرز | `src/core/model/` |
| [`timing.md`](timing.md) | التوقيت المحفوظ، وإزاحة العرض، والتصدير، ومنع التطبيق المزدوج، والحالات الإلزامية الخمس؛ والإزاحة لكل ترجمة | `src/core/model/timing.js`، والمتحكم |
| [`storage.md`](storage.md) | المفاتيح، والفهرس، والواجهة، والتزامن، والترحيل، والسعة وقرار `unlimitedStorage`؛ والتخزين المتوافق بمفاتيح جديدة، والكتابة الذرية ونسخة الحزمة، ومصالحة ما يكتبه الأول، وواجهة الحزمة والاستعادة | `src/core/store/` |
| [`messages.md`](messages.md) | MAIN → ISOLATED، ونافذة الأيقونة ← سكربت المحتوى، والصفحات ↔ المشغّل عبر التخزين؛ والرد الموسّع، وتشخيص الصفحة، والقفز، والحفظ عبر العامل | `src/content/`، `src/core/model/messages.js`، `src/background/` |
| [`interfaces.md`](interfaces.md) | بنية الشيفرة والملكية، والمتحكم، والمستخرج، ونقطتا التركيب، وتدفقا التصدير والاستيراد، ومحددات يوتيوب، والصفحات وعناوينها، وأساس الواجهة، ومراجعة لكل مرحلة لاحقة؛ والمتحكم الموسّع، ومكان الحفظ، والقفز، والمكوّنات المرفوعة، وواجهات الربط للإصدار الثاني | `src/content/`، `src/extract/index.js`، `src/player/`، `src/ui/`، `src/core/save/` |
| [`errors.md`](errors.md) | بنية الرموز والرسائل، والمجالات وبادئاتها، والعرض، وتقرير التشخيص؛ ورموز الحفظ والخانات والقفز، ومجال النسخ الاحتياطي | `src/core/errors/`، `src/core/diagnostics/` |
| [`backup.md`](backup.md) | صيغة ملف النسخة الاحتياطية: الترويسة، والإصدار، وبصمة السلامة، والأقسام، وقواعد التحقق، وسياسة التخطي الافتراضية | `src/core/backup/` (P13)، `src/core/model/bundle.js` |
| [`extraction.md`](extraction.md) | الالتقاط السلبي، ورسالة MAIN، وقواعد القبول والرفض، والممنوعات، وما ثبت وما لم يثبت | `src/main-world/`، `src/extract/` |
