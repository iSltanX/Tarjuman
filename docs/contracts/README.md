# العقود المشتركة

> **مثبّتة في P2 (2026-11-01) ومجمَّدة:** لا تتغير أثناء موجة متوازية، والحاجة إلى تغيير عقد تجعل المرحلة متعطلة حتى يحسمه المنسّق على `main`. كل عقد يشير إلى شيفرته المرجعية واختباراتها، والتوقيعات فيه مطابقة لها.

| العقد | ما يحدده | الشيفرة المرجعية |
| --- | --- | --- |
| [`data-model.md`](data-model.md) | المقطع، والمسار الإنجليزي، والبصمة، وتقرير المقارنة، والترجمة العربية، وسجل الفيديو، والانتقالات، والإعدادات، ومُلخّص الفهرس | `src/core/model/` |
| [`timing.md`](timing.md) | التوقيت المحفوظ، وإزاحة العرض، والتصدير، ومنع التطبيق المزدوج، والحالات الإلزامية الخمس | `src/core/model/timing.js`، والمتحكم |
| [`storage.md`](storage.md) | المفاتيح، والفهرس، والواجهة، والتزامن، والترحيل، والسعة وقرار `unlimitedStorage` | `src/core/store/` |
| [`messages.md`](messages.md) | MAIN → ISOLATED، ونافذة الأيقونة ← سكربت المحتوى، والصفحات ↔ المشغّل عبر التخزين | `src/content/`، `src/core/model/messages.js` |
| [`interfaces.md`](interfaces.md) | بنية الشيفرة والملكية، والمتحكم، والمستخرج، ونقطتا التركيب، وتدفقا التصدير والاستيراد، ومحددات يوتيوب، والصفحات وعناوينها، وأساس الواجهة، ومراجعة لكل مرحلة لاحقة | `src/content/`، `src/extract/index.js`، `src/player/`، `src/ui/` |
| [`errors.md`](errors.md) | بنية الرموز والرسائل، والمجالات وبادئاتها، والعرض، وتقرير التشخيص | `src/core/errors/`، `src/core/diagnostics/` |
| [`extraction.md`](extraction.md) | الالتقاط السلبي، ورسالة MAIN، وقواعد القبول والرفض، والممنوعات، وما ثبت وما لم يثبت | `src/main-world/`، `src/extract/` |
