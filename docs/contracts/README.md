# العقود المشتركة

> **مسودات** كُتبت في تأسيس الخطة. تُحدّث P1 عقد الاستخراج بما ثبت حيًا، وتثبّت P2 الجميع، ثم تُجمَّد: لا تتغير أثناء موجة متوازية، والحاجة إلى تغييرها تجعل المرحلة متعطلة حتى يحسمها المنسّق على `main`.

| العقد | ما يحدده | الحالة |
| --- | --- | --- |
| [`timing.md`](timing.md) | التوقيت المحفوظ، وإزاحة العرض، والتصدير، ومنع التطبيق المزدوج | مسودة — تثبّتها P2 |
| [`data-model.md`](data-model.md) | المقطع، والمسارات، وسجل الفيديو، والبصمة، والإعدادات، وتقرير المقارنة، ومفاتيح التخزين | مسودة — تثبّتها P2 |
| [`extraction.md`](extraction.md) | الالتقاط السلبي، والرسالة من MAIN إلى ISOLATED، وقواعد القبول والرفض، والممنوعات | مسودة — تحدّثها P1 وتثبّتها P2 |
| [`interfaces.md`](interfaces.md) | حدود الوحدات: المتحكم، والتدفقات، ونقاط التركيب، والصفحات، والرسائل، والأخطاء، وبنية الشيفرة | مسودة — تثبّتها P2 |

تضيف P2 عند التثبيت: `storage.md` و`messages.md` و`errors.md` إن فصلتها عن الملفات أعلاه.
