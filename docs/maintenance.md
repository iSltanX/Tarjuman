# دليل الصيانة والفحص الدوري لترجمان

> ترجمان يعتمد على سلوك يوتيوب غير الموثّق: طلب المشغّل للترجمة وصيغة `json3`، وعناصر المشغّل وفئاته، وأحداث التنقل والإعلانات. أي تحديث ليوتيوب أو للمتصفح قد يكسر جزءًا منه دون إنذار. هذا الدليل يقول **متى تفحص، وكيف، وماذا تراقب، وأين تُصلح**. والأوامر تُشغَّل في مجلد المشروع بـ`command node` و`command npm run` كما في جلسات هذا الجهاز.

## ١. متى

| المناسبة | الفحص |
| --- | --- |
| شهريًا | السريع (§٢) والقائمة الثابتة (§٣). |
| بعد تحديث رئيسي لـBrave أو Chrome | السريع، والدخان الحي (§٢)، والقائمة الثابتة. |
| بعد تحديث رئيسي لـEdge أو Firefox | السريع، والاختبار الحي في المتصفحات الأربعة (§٢، `test/live/stores/t3.mjs`). |
| عند خلل يلاحظه سلطان | الفحص الموجّه بحسب العَرَض (§٤)، ثم القائمة الثابتة. |
| قبل بناء حزمة جديدة | السريع، والتدقيق (§٥). |

## ٢. الفحص السريع (آلي، دقائق)

```bash
command npm run check:wave
```

```bash
command node scripts/run-tests.mjs test/e2e/static test/e2e/regression
```

```bash
command node test/e2e/live/v2/surfaces.mjs --browser brave
```

```bash
command node test/live/harness/smoke.mjs --browser brave --out docs/evidence/<المجلد>
```

```bash
command node test/live/stores/t3.mjs --browser firefox --out docs/evidence/<المجلد>/firefox
```

- **`check:wave`**: الفحص الثابت، والأسرار، واختبارات الوحدة، والبناء، والتكامل، وفحص الخطة.
- **اختبارات e2e الآلية** (P9 ثم P15): الرسائل من كل المجالات والتشخيص، والحزمة وتدقيقها (الأذونات الثلاثة وعامل الحفظ وحده)، والعيّنات العربية الحقيقية، والتعارض والفشل الجزئي ببصمة التخزين، وانحدار إصلاحي P9.
- **الأسطح الثلاثة** (`surfaces.mjs`، دخان W7 الدائم): المشغّل والمحفوظات والمحرّر عبر التخزين الحقيقي، بلا نافذة، دون حاجة إلى جسم الترجمة. وعند تغيير يمس التخزين أو حزمة الإصدار: `rollback.mjs` (الرجوع إلى `tj-v1` والعودة).
- **المتصفحات الأربعة** (`t3.mjs`، جولة النشر T3): التثبيت والدورة كلها والإبلاغ والإزالة في Brave وChrome وEdge وFirefox، ببناء التطوير لهدف كل متصفح (`--browser brave|chrome|edge|firefox`). Edge عبر CDP، وFirefox عبر WebDriver BiDi.
- **الدخان الحي** على بناء الإنتاج، بلا نافذة وبملف اختبار منفصل: تركيب الأدوات والطبقة، ونافذة الأيقونة، والصفحات، ولا أخطاء، ولا طلبات شبكة.
  - يجري تحت الأتمتة، فلا يعتمد على جسم الترجمة. يوتيوب يعيده فارغًا هناك (§٣).
  - يُسأل سلطان قبله برسالة «الاختبارات الحية» في دليل التشغيل.

### كيف تُفحص

**الاستخراج لا يُؤتمت.** قيس في P9 أن منفذ التصحيح وحده (`--remote-debugging-port`) يجعل `navigator.webdriver=true` في كل صفحة، كما يفعل الأنبوب. فيعيد يوتيوب جسم الترجمة فارغًا تحت أي تحكم. ولا تُخفى علامة الأتمتة، لأن ذلك تحايل على حماية يوتيوب. لذلك يمر الاستخراج بنقرات سلطان في نافذة عادية، والباقي آلي:

1. **الجلسة اليدوية**: نحو خمس دقائق لكل متصفح.

   ```bash
   command node test/e2e/live/hand.mjs --browser brave --live <معرّف البث المسجّل>
   ```

   - تُفتح نافذة عادية ببناء الإنتاج وأربعة تبويبات: يدوي، وتلقائي، وطويل، وبث مسجّل.
   - سلطان يضغط في كل تبويب: **⤓ EN** ← «تنزيل SRT»، ويختار «مقاطع أطول» في التلقائي.
   - وفي تبويب TED يضغط «نسخ تعليمات الترجمة».
   - السكربت يراقب مجلد التنزيل ونص التعليمات في الحافظة فقط، ثم يغلق النافذة ويقارن الملفات بايتًا بالمراجع.
   - ثم يُعاد الأمر بـ`--browser chrome`. ملف Chrome فيه الإضافة محمّلة يدويًا من مجلد ثابت، فلا يلزم تحميل جديد.

2. **البث المسجّل**: إن حُذف أو أُخفي فاختر غيره (جلسة مؤتمتة لا تحتاج الجسم):

   ```bash
   command node test/e2e/live/find-live.mjs
   ```

3. **البنود المؤتمتة**: بلا ترجمة، وبإعلان.

   ```bash
   command node test/e2e/live/list.mjs --browser chrome --only nocap,ad
   ```

4. **الدورة الكاملة** (عند تغيير كبير):

   ```bash
   command node test/e2e/live/cycle.mjs library --browser brave
   ```

5. **رحلة الإصدار الثاني** (عند تغيير كبير أو قبل حزمة): الترقية ثم الجلسة اليدوية ثم «اسأل» ثم الرحلة، في Brave ثم Chrome. التفاصيل والترتيب في [`test/e2e/README.md`](../test/e2e/README.md) §«الإصدار الثاني».

   ```bash
   command node test/e2e/live/v2/hand.mjs --browser brave --long 8-m7hqOqs9Y
   ```

   ```bash
   command node test/e2e/live/v2/journey.mjs --browser brave
   ```

   - في الجلسة اليدوية: ⤓ EN ← «تنزيل الملف» ثم «نسخ التعليمات» في كل تبويب، وفي الطويل مرة ثانية بعد «خيارات احتياطية» ← «تقسيم الملف إلى أجزاء».
   - الرحلة تحتاج ترجمة الطويل في `p15-work/translations/` (لا تُحفظ في المستودع).

   ثم `finish --video manual` و`finish --video asr` و`restart`. الترجمة العربية الحقيقية للفيديوهين في `test/e2e/fixtures/`.

قبل أي فحص حي: رسالة «الاختبارات الحية» لسلطان وانتظار موافقته. والأدلة في `docs/evidence/<المعرّف>/`، منقّاة من أي رابط أو رمز.

## ٤. ماذا تراقب وأين تُصلح

| العَرَض | الأرجح أنه | أين تبدأ |
| --- | --- | --- |
| «تعذّر استخراج الترجمة (استجابة فارغة)» في تصفح عادي دائمًا | يوتيوب صار يشترط شيئًا جديدًا في طلب الترجمة، أو غيّر نقله | `src/main-world/capture.js` (الالتقاط السلبي)، و`src/extract/` (المحوّل). **لا** إعادة طلب، ولا رموز، ولا انتحال عميل (product-spec §٤). |
| «صيغة الترجمة غير مدعومة» أو فشل الثوابت (`EX_INVARIANT_FAILED`) | تغيّرت بنية `json3` (`events` و`segs` و`tOffsetMs`) أو ظهرت صيغة ASR جديدة | `src/core/convert/` بعينة حقيقية منقّاة جديدة في `test/fixtures/json3/` |
| رفض `EX_WRONG_VIDEO` لكل الفيديوهات، أو التقاط فيديو سابق | تغيّر توقيت التنقل أو المعاملات (`v` و`lang` و`kind` و`tlang`) | `src/extract/timedtext-params.js` و`pending.js` و`capture-store.js` |
| اختفاء أزرار ترجمان أو موضع خاطئ في الشريط | تغيّر DOM المشغّل (`.ytp-right-controls`، و`ytp-autohide`، وأحجام الشريط) | `src/player/youtube-dom.js` وحده (محددات يوتيوب معزولة فيه)، ثم `src/player/controls/bar.js` |
| الترجمة تظهر فوق الإعلان، أو لا تعود بعده | تغيّرت فئات الإعلان (`ad-showing` و`ad-interrupting`) | `src/player/youtube-dom.js` و`src/player/watch/player-state.js` |
| ترجمة الفيديو السابق تبقى بعد التنقل | تغيّر حدث التنقل (`yt-navigate-finish`) | `src/player/watch/navigation.js` |
| الترجمة لا تظهر في ملء الشاشة | تغيّر عنصر ملء الشاشة | `src/player/watch/fullscreen.js` |
| تعطل العرض كله في صفحة يوتيوب | سياسة أمان جديدة (CSP أو Trusted Types) | `src/player/overlay/sheet.js` والطبقة: DOM وCSSOM فقط، لا HTML نصي |
| الإضافة لا تُحمَّل في Brave بعد تحديث | تغيّر دعم `--load-extension` أو وضع المطوّر | التحميل اليدوي من صفحة الإضافات (دليل الاستخدام §١) |
| امتلاء التخزين | محفوظات كبيرة جدًا | الإعدادات ← السعة، وتصدير ما لا يلزم ثم حذفه |
| «تعذّر الحفظ في المكان المختار» أو مجلد فرعي لا يُنشأ | تغيّر سلوك `chrome.downloads` أو إعداد المتصفح «اسأل» | `src/core/save/` و`src/background/` (العامل الخلفي للحفظ وحده)، والعقد §١٣ |
| تفعيل ترجمة في المحفوظات لا ينعكس في المشغّل (أو العكس) | تغيّر توقيت `storage.onChanged` أو تأخير التبويب المخفي | `src/content/controller.js` و`src/pages/library/view.js` (مؤقت إعادة التحميل)، ثم `surfaces.mjs` |
| استعادة نسخة احتياطية تُرفض كلها | تغيّر بنية الملف أو بصمة السلامة | `src/core/backup/` وعقد `docs/contracts/backup.md`، ولا تُخفَّف بصمة السلامة |

قواعد ثابتة عند الإصلاح:

- الإصلاح يمر بفحص الطبقة السريعة، ثم القائمة الثابتة في المتصفحين: Brave أولًا ثم Chrome.
- ولا يُعدّ ناجحًا إلا بدليل حي حين يمسّ الاستخراج أو المشغّل.

## ٥. بناء الحزم وإعادة التثبيت

```bash
command node scripts/release/package.mjs
```

```bash
command node scripts/release/audit.mjs release/tarjuman-<الإصدار>
```

- ينتج المجلد والأرشيف وملف البصمات في `release/` (متجاهَل في Git).
- التدقيق يفحص الملفات المشحونة نفسها:
  - الأذونات `storage` و`unlimitedStorage` و`downloads` وحدها، والعامل الخلفي `background/worker.js` وحده.
  - واجهة التنزيلات في `core/save` (الصفحات) والعامل وحدهما، ولا تصل إليها شيفرة عالم الصفحة، ومحصورة في `download` و`search` بمعرّف ما نزّلته الإضافة؛ وكل ملف يشير إليه البيان أو صفحة أو نمط موجود غير فارغ، وخطوط الواجهة برخصها.
  - لا طلب شبكة إلا قراءة خطوط الترجمة من الحزمة، وطلب البلاغ الوحيد من صفحة الإعدادات (جولة النشر T2.1).
  - لا رابط إلا المسمّى: رابطا «حول»، وأصل صور المحفوظات، وخادم البلاغات وإذنه الاختياري.
  - لا شيفرة بعيدة، ولا خطاف تطوير.
  - خطوط الترجمة الأربعة بملفيها ورخصة OFL لكل منها.
  - إشعارات الأطراف الثالثة `THIRD_PARTY_NOTICES.txt` في جذر الحزمة: سطر حقوق كل خط مشحون، ونص ترخيص Lucide حرفيًا، وترخيص esbuild (جولة النشر T4).
  - ولا ملف غير متوقع: ويُقبل منذ جولة صقل الواجهات خطا الواجهة المضمّنان `ui/fonts/ui/` (ويكشفهما البيان ليوتيوب وحده كخطوط الترجمة) ورخصتهما، وأيقونات الإضافة الأربع `icons/`، ومنذ T4 ملف الإشعارات.
- **التدقيق لهدف Firefox:** `command node scripts/release/audit.mjs dist-firefox --target firefox` بالفحوص نفسها، ومعها إعدادات Gecko المعتمدة وسكربت الخلفية بدل عامل الخدمة.

### حزم المتاجر (جولة النشر T4)

```bash
command npm run package
```

- يبني حزمة التثبيت الشخصي السابقة، ثم في `release/store/`:
  - `tarjuman-<الإصدار>-chrome.zip` وتُرفع إلى Chrome Web Store.
  - `tarjuman-<الإصدار>-edge.zip` وتُرفع إلى Edge Add-ons، وهي بايتات حزمة Chrome نفسها.
  - `tarjuman-<الإصدار>-firefox.zip` وتُرفع إلى Firefox Add-ons.
  - `tarjuman-<الإصدار>-source.zip` شيفرة المصدر لمراجعي Firefox، وتعليمات البناء فيها `SOURCE-README.txt` بالإنجليزية.
  - `SHA256SUMS` و`tarjuman-<الإصدار>-store.json` (الالتزام والتدقيق وإعادة البناء وبصمة كل ملف).
- لا تُكتب الحزم إن فشل شيء مما يلي:
  - تدقيق هدف كل حزمة.
  - مطابقة رقم البيان لـ`package.json`.
  - خلوّ الحزم من مسار الجهاز والرموز والمفاتيح.
  - إعادة البناء من حزمة المصدر في مجلد آخر بايتًا بايتًا للهدفين، وهو ما يفعله مراجع Firefox.
- البيان في جذر كل حزمة متجر، لا داخل مجلد.
- حزمة المصدر من قائمة صريحة في `scripts/release/store.mjs`: `src/` وسكربتا البناء والأهداف و`package.json` وملف القفل و`LICENSE` والإشعارات. لا أدلة، ولا تقارير، ولا اختبارات، ولا `node_modules`.
- البناء يكتب مسار كل ملف مصدر في تعليق داخل الحزمة نسبةً إلى جذر المستودع (`absWorkingDir`)، فلا يختلف ببناء من مجلد آخر.
- `LICENSE` معتمد (سلطان، 2026-11-04). وإن عاد أوله سطر `[قرار]` نبّه الأمر بأنه مسودة، فلا تُرفع الحزم.
- **عند إضافة خط أو أيقونة:** أعد توليد الإشعارات بـ`command node scripts/release/notices.mjs`. خط بلا نسبة يُفشل التوليد، وأيقونة في `src/ui/icons.js` بلا تصنيف في `LUCIDE_ICONS` أو `ORIGINAL_ICONS` تُفشل اختبار الوحدة. و`check` يفحص المطابقة بـ`--check`.
- **فحص Firefox:** `command npm run lint:firefox`. المتوقع تحذير واحد عن Firefox لأندرويد، والإضافة لسطح المكتب وحده.
- إعادة التثبيت بنسخ الملفات إلى المجلد الدائم نفسه (دليل الاستخدام §٩).
- **الرجوع إلى الإصدار الأول** عند خلل يمنع الاستعمال: حزمة الوسم `tj-v1` بسكربت حزمته نفسه (كما يبنيها `buildV1` في `test/e2e/live/v2/lib.mjs`)، ثم نسخ ملفاتها إلى المجلد الدائم نفسه. خذ نسخة احتياطية من الإعدادات قبلها. ثبت في P15 أن الأول يقرأ مكتبة الثاني ويكتب عليها، وأن العودة إلى الثاني بلا فقد.
