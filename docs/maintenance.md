# دليل الصيانة والفحص الدوري لترجمان

> ترجمان يعتمد على سلوك يوتيوب غير الموثّق: طلب المشغّل للترجمة وصيغة `json3`، وعناصر المشغّل وفئاته، وأحداث التنقل والإعلانات. أي تحديث ليوتيوب أو للمتصفح قد يكسر جزءًا منه دون إنذار. هذا الدليل يقول **متى تفحص، وكيف، وماذا تراقب، وأين تُصلح**. والأوامر تُشغَّل في مجلد المشروع.

## ١. متى

| المناسبة | الفحص |
| --- | --- |
| شهريًا | السريع (§٢) والقائمة الثابتة (§٣). |
| بعد تحديث رئيسي لـBrave أو Chrome | السريع، والدخان الحي (§٢)، والقائمة الثابتة. |
| بعد تحديث رئيسي لـEdge أو Firefox | السريع، والاختبار الحي في المتصفحات الأربعة (§٢، `test/live/stores/t3.mjs`). |
| عند خلل يلاحظه سلطان | الفحص الموجّه بحسب العَرَض (§٤)، ثم القائمة الثابتة. |

## ٢. الفحص السريع (آلي، دقائق)

```bash
npm run check:all
```

```bash
node test/live/identity/run.mjs --browser brave
```

```bash
node test/live/harness/smoke.mjs --browser brave
```

```bash
node test/live/stores/t3.mjs --browser firefox
```

```bash
npm run youtube:shapes -- --browser chrome
```

- **التشغيل الأسبوعي:** CI يشغّل `check:all` كل اثنين (`schedule` في `.github/workflows/ci.yml`) بلا دفع، فيظهر انكسار تحديث أداة أو متصفح. وتنبيهات أدوات البناء من Dependabot (`.github/dependabot.yml`) طلبات سحب مجمّعة: تحديثها يغيّر الحزم، فتُعاد مطابقة البصمات (§٥) قبل الدمج.
- **`check:all`**: الفحص الثابت، والأسرار، وتغطية التوطين، والإشعارات، والخصوصية، ومواد المتاجر، واختبارات الوحدة، والبناءان، والتكامل، وe2e الآلية، و`web-ext lint`.
- **اختبارات e2e الآلية**: الرسائل من كل المجالات والتشخيص، والحزمة وتدقيقها (الأذونات الثلاثة وعامل الحفظ وحده)، والعيّنات العربية الحقيقية، والتعارض والفشل الجزئي ببصمة التخزين، وانحدار إصلاحي P9.
- **الأسطح** (`test/live/identity/run.mjs`، في Brave وChrome): المحفوظات والإعدادات ونافذة الأيقونة والمحرّر ولوحة النص وشريط المشغّل على يوتيوب عبر التخزين الحقيقي، بلا نافذة، دون حاجة إلى جسم الترجمة. وعند تغيير يمس التخزين أو حزمة الإصدار: `rollback.mjs` (الرجوع إلى `tj-v1` والعودة).
- **المتصفحات الأربعة** (`t3.mjs`، جولة النشر T3): التثبيت والدورة كلها ونسخ البلاغ والإزالة في Brave وChrome وEdge وFirefox، ببناء التطوير لهدف كل متصفح (`--browser brave|chrome|edge|firefox`). Edge عبر CDP، وFirefox عبر WebDriver BiDi.
- **«هل تغيّر يوتيوب؟»** (`youtube:shapes`، ف8): جولة حية واحدة بلا نافذة وبلا الإضافة على الفيديو المرجعي، تقارن ما يعتمد عليه ترجمان أشكالًا بلا قيم بخط الأساس [`test/fixtures/youtube/shapes-baseline.json`](../test/fixtures/youtube/shapes-baseline.json): وجود عناصر `SELECTORS` وزمن المشغّل (`timeDisplay` داخل الأدوات اليسرى، يقيس به الشريط قصّ الزمن)، وشكل طلب الترجمة للفيديو المرجعي (أسماء المعاملات)، وشكل قائمة المسارات في بيانات المشغّل، وأحداث التنقل بعد انتقال فعلي إلى فيديو مقترح: إن لم يتغيّر `v` في العنوان طبعت «تعذّر التنقل» وخرجت بالرمز 1 دون كتابة شيء. تطبع الفروق («غاب: dom.rightControls») وصف السجل لـ§٦، ولا تحكم بالفشل لأن يوتيوب يجرّب واجهات مختلفة. وبعد قبول فرق: `--update` يكتب اللقطة خط أساس جديدًا. خط الأساس الحالي من يوتيوب الحقيقي (Chrome 157، 2026-11-13، جولة بإذن سلطان). ومنطقها النقي في `scripts/youtube-shapes.mjs` (اختبارات وحدة).
- **الدخان الحي** على بناء الإنتاج، بلا نافذة وبملف اختبار منفصل: تركيب الأدوات والطبقة («مركّبة» لكل منهما؛ و«بانتظار» أو `CT_PLAYER_NOT_FOUND` يُسقط الفحص، ف8 وف10)، ونافذة الأيقونة، والصفحات، ولا أخطاء، ولا طلبات شبكة.
  - يجري تحت الأتمتة، فلا يعتمد على جسم الترجمة. يوتيوب يعيده فارغًا هناك (§٣).
  - يُسأل سلطان قبله كما في «الاختبارات الحية» من [دليل المطوّرين](development.md#الاختبارات-الحية).

### كيف تُفحص

**الاستخراج لا يُؤتمت.** قيس في P9 أن منفذ التصحيح وحده (`--remote-debugging-port`) يجعل `navigator.webdriver=true` في كل صفحة، كما يفعل الأنبوب. فيعيد يوتيوب جسم الترجمة فارغًا تحت أي تحكم. ولا تُخفى علامة الأتمتة، لأن ذلك تحايل على حماية يوتيوب. لذلك يمر الاستخراج بنقرات سلطان في نافذة عادية، والباقي آلي:

1. **الجلسة اليدوية**: نحو خمس دقائق، في Brave بنافذة عادية.

   ```bash
   command npm run package
   TJ_PROFILE_ROOT=<مجلد خارج المستودع> command node test/live/aa5/hand.mjs --minutes 15
   ```

   - تُفتح نافذة عادية ببناء الإنتاج على فيديو له مسار إنجليزي ومسار بغير الإنجليزية (AA5).
   - سلطان يضغط CC ثم أيقونة ترجمان ← «تنزيل الملف»، ثم يبدّل المسار من الترس ويكرر.
   - السكربت لا ينقر شيئًا: يراقب مجلد التنزيل فقط، ثم يغلق النافذة ويفحص كل ملف (الاسم والحجم والبصمة وعدد المقاطع ورمز اللغة).

2. **البث المسجّل**: إن حُذف أو أُخفي فاختر غيره (جلسة مؤتمتة لا تحتاج الجسم):

   ```bash
   node test/e2e/live/find-live.mjs
   ```

3. **البنود المؤتمتة**: بلا ترجمة، وبإعلان.

   ```bash
   node test/e2e/live/list.mjs --browser chrome --only nocap,ad
   ```

4. **الدورة الكاملة** (عند تغيير كبير): بناء التطوير في المتصفحات الأربعة، من التثبيت والالتقاط والتنزيل والرفع والعرض والمحرّر حتى
   النسخة الاحتياطية والإزالة والاستعادة (جولة النشر T3). كان هنا سكربت دورة قديم استُبدل منذ إعادة تصميم الهوية
   (تدقيق Fable، FA-06).

   ```bash
   node test/live/stores/t3.mjs --browser brave --out <مجلد خارج المستودع>
   ```

   - ثم `--browser chrome` و`edge` و`firefox`. وأسطح الهوية ولوحة اللوحة الجانبية في `test/live/identity/run.mjs`.
   - **تخطيط صفحة المشاهدة:** يوتيوب يجرّب لبعض ملفات التعريف الجديدة تخطيطًا يقع فيه العمود الثانوي فوق جزء من الفيديو (رُصد في
     Edge، تدقيق Fable FA-22). اللوحة تنتقل فيه تحت الفيديو (`chooseColumn` في `src/player/panel/column.js`)؛ فإن ظهر في جولة فتحقق أن
     `place` «below» وأن مضيف اللوحة في `#below` لا فوق المشغّل، وإن ظهر تخطيط بلا `ytd-watch-flexy` فالمحددات في `column.js` وحدها.

5. **الرجوع إلى الإصدار الأول** (عند تغيير في التخزين أو قبل حزمة): الرجوع إلى `tj-v1` ثم العودة دون فقد، في Brave ثم Chrome. التفاصيل في [`test/e2e/README.md`](../test/e2e/README.md) §«الإصدار الثاني».

   ```bash
   command node test/e2e/live/v2/rollback.mjs --browser brave
   ```

قبل أي فحص حي: رسالة لسلطان وانتظار موافقته ([الاختبارات الحية](development.md#الاختبارات-الحية)). والنتائج في `test-results/live/` (أو `--out`)، منقّاة من أي رابط أو رمز، ولا تُحفظ في المستودع.

قواعد ثابتة عند الإصلاح:

- الإصلاح يمر بفحص الطبقة السريعة، ثم القائمة الثابتة في المتصفحين: Brave أولًا ثم Chrome.
- ولا يُعدّ ناجحًا إلا بدليل حي حين يمسّ الاستخراج أو المشغّل.

## ٥. بناء الحزم وإعادة التثبيت

```bash
node scripts/release/package.mjs
```

```bash
node scripts/release/audit.mjs release/tarjuman-<الإصدار>
```

- ينتج المجلد والأرشيف وملف البصمات في `release/` (متجاهَل في Git).
- **قبل البناء وبعده** (تدقيق 7a66f91، U61):
  - يفحص المصدر بـ`check-static` أولًا.
  - ثم يبني في مجلد مرحلي ويدقق.
  - فلا يكتب في `release/` شيئًا إن فشل أحدهما، ويبقى ما كان فيه.
- **ملف البصمات `.json`** (U62 وU63):
  - فيه الالتزام وحال الشجرة من Git هذا المستودع وحده، وكلاهما `null` بلا Git (لا «نظيفة»).
  - وفيه بيئة البناء `build` (Node وzlib والمعمارية والنظام).
- **مجلد الإخراج** (U60): البناء لا يمسح إلا مجلدًا غائبًا أو فارغًا أو مجلد بناء سابقًا، أي بيان ترجمان في جذره ولا شيء غير مخرجات البناء.
  - فـ`--out` إلى مجلد فيه غير ذلك (ومنه `.git` وأشجار العمل ومجلد المستخدم وما داخل `src`) يُرفض قبل أي مسح.
- **القواعد المشتركة** (`scripts/code-rules.mjs`): يطبقها الفحص الثابت على المصدر والتدقيق على الحزمة، بلا استثناء لملف أو سطر. فهي تمنع في المصدر كله أيضًا ما يلي، ولكلٍّ بديل:
  - الوصول المحسوب بوصل نصوص، مثل `o[k + 'px']`. والبديل القالب `` o[`${k}px`] `` أو `Map`.
  - تفكيك `chrome` و`globalThis` و`window`، مثل `const { runtime } = chrome`. والبديل `chrome.runtime`.
  - استدعاء `.constructor(`.
  - متغيرات Node العامة (`node-global`، تحقق Gemini ع-٥): `Buffer` و`setImmediate` و`clearImmediate` و`process.` و`require(` و`__dirname` و`__filename`. الاختبارات تعمل في Node فتنجح بها، والشيفرة تتعطل في المتصفح. والبديل `TextEncoder` و`setTimeout`.
  - وهي نصية: تحرس من الخطأ لا من التمويه المتعمد.
- **الفحص الثابت وحده:** محوّل `chrome.storage.local` (`src/core/store/area.js`) لا يستورده إلا `src/core/store/index.js` والعامل الخلفي، فلا يكتب سياق آخر في التخزين بمساحة باسم غير `area` (ع-٢١).
- **فحص الأسرار** (`check-secrets`): مع أسرار يوتيوب والرموز الطويلة ومسارات الجهاز، الأسرار العامة بصيغها (رموز GitHub وnpm وSlack، ومفاتيح AWS وGoogle، وسرّ عميل OAuth، والمفتاح الخاص، وسرّ أو كلمة مرور مسنَدة بالاسم)، ويرفض الملفات المتتبَّعة باسم `.env*` و`.npmrc` و`*.pem` و`*.key` و`*.p12` و`*.pfx` ومفاتيح SSH (ع-٢١).
  - ومعها (ن-١٢): سرّ AWS مسنَدًا باسمه (`aws_secret_access_key` بصيغه)، وكتلة PGP الخاصة، ومفتاحا Stripe الحيّان (`sk_live_` و`rk_live_`)، ورمز GitHub القديم (40 محرفًا ست عشريًا باسم ينتهي بـ`token` أو بترويسة التخويل). ويفحص `.sh` و`.ts` وأخواتهما.
  - ولا يكشف بعد: ملفات بلا امتداد أو بامتداد غير مفحوص (`.ini` و`prod.env` و`LICENSE`)، وكلمة المرور القصيرة أو غير المقتبسة، ورابط Slack الخطافي.
- التدقيق يفحص الملفات المشحونة نفسها، بقواعد الفحص الثابت التي بلا استثناء (`scripts/code-rules.mjs`، ومنها الصيغ الديناميكية والروابط بلا بروتوكول) ثم قواعده هو:
  - الأذونات `storage` و`unlimitedStorage` و`downloads` وحدها، والعامل الخلفي `background/worker.js` وحده.
  - واجهة التنزيلات في `core/save` (الصفحات) والعامل وحدهما، ولا تصل إليها شيفرة عالم الصفحة، ومحصورة في `download` و`search` بمعرّف ما نزّلته الإضافة؛ وكل ملف يشير إليه البيان أو صفحة أو نمط موجود غير فارغ، وخطوط الواجهة برخصها.
  - لا طلب شبكة إلا قراءة خطوط الترجمة من الحزمة، ولا اسم لخادم البلاغات القديم في أي ملف ولا طلب في حزمة الإعدادات (`no-report-channel`، و1).
  - لا إذن مضيف إلزامي ولا اختياري (`no-host-or-optional-permissions`)، ولا طلب إذن أو موافقة إلا في حزمة الإعدادات (`permissions-request-settings-only`: موافقة صور المحفوظات في Firefox).
  - لا رابط إلا المسمّى: روابط «حول» الثلاثة (الموقع والمستودع والدعم)، وأصل صور المحفوظات.
  - لا شيفرة بعيدة، ولا خطاف تطوير.
  - خطوط الترجمة الأربعة بملفيها ورخصة OFL لكل منها.
  - إشعارات الأطراف الثالثة `THIRD_PARTY_NOTICES.txt` في جذر الحزمة: سطر حقوق كل خط مشحون، ونص ترخيص Lucide حرفيًا، وترخيص esbuild (جولة النشر T4).
  - ولا ملف غير متوقع: ويُقبل منذ جولة صقل الواجهات خطا الواجهة المضمّنان `ui/fonts/ui/` (ويكشفهما البيان ليوتيوب وحده كخطوط الترجمة) ورخصتهما، وأيقونات الإضافة الأربع `icons/`، ومنذ T4 ملف الإشعارات.
- **التدقيق لهدف Firefox:** `node scripts/release/audit.mjs dist-firefox --target firefox` بالفحوص نفسها، ومعها إعدادات Gecko المعتمدة وسكربت الخلفية بدل عامل الخدمة.

### حزم المتاجر (جولة النشر T4)

```bash
npm run package
```

- يبني حزمة التثبيت الشخصي السابقة، ثم في `release/store/`:
  - `tarjuman-<الإصدار>-chrome.zip` وتُرفع إلى Chrome Web Store.
  - `tarjuman-<الإصدار>-edge.zip` وتُرفع إلى Edge Add-ons، وهي بايتات حزمة Chrome نفسها.
  - `tarjuman-<الإصدار>-firefox.zip` وتُرفع إلى Firefox Add-ons.
  - `tarjuman-<الإصدار>-source.zip` شيفرة المصدر لمراجعي Firefox، وتعليمات البناء فيها `SOURCE-README.txt` بالإنجليزية.
  - `SHA256SUMS` و`tarjuman-<الإصدار>-store.json` (الالتزام والتدقيق وإعادة البناء وبصمة كل ملف، وبيئة البناء `build`).
- **البصمات تتبع zlib** (U63): بصمة كل أرشيف تتبع مكتبة zlib المربوطة بـNode. فـNode من Homebrew (zlib النظام) يعطي أرشيفًا غير ما تعطيه نسخ Node الرسمية (zlib المضمّن)، والملفات داخلهما متطابقة بايتًا. فاذكر البيئة مع كل جدول بصمات، وقارن ملفًا ملفًا إن اختلفت (`store/README.md` §٤).
- لا تُكتب الحزم إن فشل شيء مما يلي:
  - الفحص الثابت على المصدر.
  - تدقيق هدف كل حزمة.
  - مطابقة رقم البيان لـ`package.json`.
  - خلوّ الحزم من مسار الجهاز والرموز والمفاتيح.
  - إعادة البناء من حزمة المصدر في مجلد آخر بايتًا بايتًا للهدفين، وهو ما يفعله مراجع Firefox.
- البيان في جذر كل حزمة متجر، لا داخل مجلد.
- حزمة المصدر من قائمة صريحة في `scripts/release/store.mjs`: `src/` وسكربتا البناء والأهداف و`package.json` وملف القفل و`LICENSE` والإشعارات. لا أدلة، ولا تقارير، ولا اختبارات، ولا `node_modules`.
- البناء يكتب مسار كل ملف مصدر في تعليق داخل الحزمة نسبةً إلى جذر المستودع (`absWorkingDir`)، فلا يختلف ببناء من مجلد آخر.
- `LICENSE` معتمد (سلطان، 2026-11-04). وإن عاد أوله سطر `[قرار]` نبّه الأمر بأنه مسودة، فلا تُرفع الحزم.
- **عند إضافة خط أو أيقونة:** أعد توليد الإشعارات بـ`node scripts/release/notices.mjs`. خط بلا نسبة يُفشل التوليد، وأيقونة في `src/ui/icons.js` بلا تصنيف في `LUCIDE_ICONS` أو `ORIGINAL_ICONS` تُفشل اختبار الوحدة. و`check` يفحص المطابقة بـ`--check`.
- **فحص Firefox:** `npm run lint:firefox`. المتوقع: بلا خطأ ولا تحذير، فالأمر يعامل كل تحذير خطأً (`--warnings-as-errors`) فيُسقط تحذيرٌ واحد `check:all`.
- إعادة التثبيت بنسخ الملفات إلى المجلد الدائم نفسه (دليل الاستخدام §٩).
- **الرجوع إلى الإصدار الأول** عند خلل يمنع الاستعمال: حزمة الوسم `tj-v1` بسكربت حزمته نفسه (كما يبنيها `buildV1` في `test/e2e/live/v2/lib.mjs`)، ثم نسخ ملفاتها إلى المجلد الدائم نفسه. خذ نسخة احتياطية من الإعدادات قبلها. ثبت في P15 أن الأول يقرأ مكتبة الثاني ويكتب عليها، وأن العودة إلى الثاني بلا فقد.
