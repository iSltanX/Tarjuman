## لماذا هذه المرحلة وحدها

P15 هي الحكم التكاملي النهائي على الإصدار الثاني: رحلة المستخدم كاملة في المتصفحين، والرجوع إلى حزمة `tj-v1`، ومسارات الإلغاء والتعارض. نجاح كل سطح منفردًا ليس نجاح التكامل، ولذلك تعمل وحدها بصلاحية إصلاحات تكامل صغيرة موثّقة في `src/**`.

## ترتيب الدمج والملفات المشتركة

مرحلة واحدة. تملك `test/e2e/` و`scripts/release/` والأدلة الثلاثة في `docs/`، وتلمس `src/**` لإصلاحات موثّقة فقط يراجعها المنسّق ملفًا ملفًا.

## البوابة

`npm run plan:check` و`npm run check:wave`، ثم مراجعة أدلة P15 الحية وقائمة الجاهزية. بعد النجاح يوضع الوسم `tj-v2` على `main` (الإصدار الثاني). الموجة الأخيرة في هذه الخطة: لا وسم أساس بعدها.
