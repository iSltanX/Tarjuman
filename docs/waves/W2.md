## لماذا هذه المرحلة وحدها

P2 تثبّت العقود والهيكل ونقاط التركيب التي تبني عليها W3 وW4 بالتوازي. تمسّ `manifest.json` والبناء والمتحكم ونموذج البيانات، فلا يجاورها أحد. وبعد تحققها تُجمَّد العقود.

## ترتيب الدمج والملفات المشتركة

مرحلة واحدة. تملك في هذه الموجة كل الملفات المشتركة للمنتج (`package.json` و`scripts/` و`src/manifest.json` و`src/content/` و`src/core/model/` و`src/ui/` و`src/player/youtube-dom.js` و`docs/contracts/` و`test/helpers/` و`test/live/harness/`).

## البوابة

`npm run plan:check` و`npm run check`، ثم تحميل الإضافة المبنية في Brave، وفتح صفحة مشاهدة دون أخطاء في وحدة التحكم، وفتح الصفحات الأربع. بعد النجاح يوضع الوسم `tj-W3/base`.
