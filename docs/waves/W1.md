## لماذا هذه المرحلة وحدها

P1 أكبر خطر في المشروع وبوابة قرار. لا يُبنى شيء فوق استخراج لم يثبت، ولا يجاورها عمل لأنها تنشئ ملفات الأساس (`package.json` و`manifest.json` وهيكل `src/`).

## ترتيب الدمج والملفات المشتركة

مرحلة واحدة. تملك في هذه الموجة `package.json` و`scripts/` و`src/manifest.json` و`src/content/` و`test/live/` و`docs/contracts/extraction.md`، ولا يشاركها أحد.

## البوابة والقرار G1

- **الفحص:** `npm run plan:check` و`npm run check`، ثم مراجعة أدلة P1 الحية (لا إعادة كاملة؛ إعادة التقاط واحد على Brave فقط إن نقص دليل معيار).
- **إن كانت النتيجة «نجاح»:** تُفتح G1 تلقائيًا ويوضع الوسم `tj-W2/base`.
- **إن كانت «جزئي» أو «فشل»:** يعرض المنسّق تقرير P1 وأسبابه وبدائله، ويسأل سلطان، ولا يضع وسم W2 قبل قراره المكتوب. خيارات القرار في `plan.json` (`gates[G1].options`)، ولا يتحول المشروع تلقائيًا إلى «عارض SRT».

### تقرير الموجة — W1

- المراحل بترتيب الدمج: P1: `90df48c` (دمج `tj/P1-live-extraction` عند `17145aa`).
- التعارضات وحلولها: لا شيء.
- فحص «لا تغيير سقط»: ناجح — 135 من 135 ملفًا مطابقة لرأس التكامل حرفيًا.
- بوابة الموجة: `npm run plan:check` سليمة، لا أخطاء · `npm run check` ناجح (`check:static`، و`check:secrets` على 59 ملفًا، و32/32 اختبارًا، والبناء) · الدخان الحي: ناجح بمراجعة أدلة P1 — كل معيار من التسعة له دليل موجود ومطابق للتقرير، فلم تلزم إعادة التقاط على Brave.
- البوابة المحسومة: G1: مفتوحة — تلقائيًا بنتيجة P1 «نجاح» (الالتقاط السلبي يعمل في Brave وChrome غير المؤتمتين لليدوي والتلقائي، بلا طلب جديد ولا تخزين رموز). لا قرار مطلوب من سلطان.
- الموجة التالية: W2 تُفتح بوضع الوسم `tj-W2/base` على التزام التحقق هذا بعد تقديم `main` إليه.
- worktrees وفروع للتنظيف: worktree `.claude/worktrees/tj-P1` (نظيف) وفرعه `tj/P1-live-extraction` (مدمج) — بانتظار موافقة سلطان. وفرع التكامل `tj-int/W1` يُحذف بعد التقديم.
- ملاحظات تنتقل إلى ما بعدها (من تقرير P1، مسجّلة لا منفّذة): الحساب المسجَّل والبث الجاري و`srv3` لم تُختبر؛ والجسم الفارغ تحت الأتمتة (`navigator.webdriver=true`) يجعل الاختبار الحي الآلي لا يثبت الالتقاط نفسه، فالأدلة الحية للمراحل اللاحقة تحتاج جلسات غير مؤتمتة؛ وفي Brave يختار يوتيوب العربية تلقائيًا فيلزم المستخدم اختيار English (تلميح محتمل في P5/P6)؛ وصفحة الفحص `src/pages/poc/` ومشغّل خطتها للإثبات فقط وتُزال في P2.
