# وثائق ترجمان

| الوثيقة | ما فيها |
| --- | --- |
| [`product-spec.md`](product-spec.md) | الفكرة، والجمهور، والدورة، والحدود، والوظائف، وتوزيع الواجهة، وعقد التوقيت، والاستخراج، ومراجعة التقريرين، والقرارات، وخارج النطاق، والمخاطر، والقرارات المفتوحة، والمراحل المشتقة. |
| [`ui-redesign.md`](ui-redesign.md) | إعادة تصميم الواجهات: النظام البصري المشترك (`src/ui/`)، وقرارات الإعدادات والمحفوظات ونافذة الأيقونة وقوائم المشغّل، وما ينتظر الإصدار الثاني، والتحقق الحي. |
| [`requirements-map.md`](requirements-map.md) | خريطة المتطلبات ← المراحل ← معايير القبول (مولّدة). |
| [`phases/`](phases/) | ملف لكل مرحلة: الهدف، والنطاق، والمهام، والاعتماديات، والملفات، والقبول، والمخاطر، والحالة، والسجل، والتقرير. |
| [`waves/`](waves/) | سجل لكل موجة يكتبه منسّقها. |
| [`delivery/runbook.md`](delivery/runbook.md) | دليل التشغيل: الأدوار والأوامر والحالات والملكية والفحوص والتقارير. |
| [`delivery/waves.md`](delivery/waves.md) | الموجات وترتيب الدمج وملكية الملفات والملفات المشتركة ونقاط التجميد. |
| [`contracts/`](contracts/) | العقود المشتركة: ثبّتتها P2 للإصدار الأول، وتحدّثها P10 للإصدار الثاني بواجهات الربط المثبتة في `delivery/waves.md`. |
| `evidence/<ID>/` | أدلة كل مرحلة (تنشئها جلساتها). |
