# دليل المطوّرين

البناء والتثبيت من الشيفرة والفحوص وهيكل المستودع والتغليف. والمدخل العام للمستودع [`README.md`](../README.md)، وقواعد المساهمة في [`CONTRIBUTING.md`](../.github/CONTRIBUTING.md).

## المتطلبات

- [Node.js](https://nodejs.org/) ‏22 فأحدث (يُفحص CI على 22 و24).
- `npm ci` يثبّت أدوات البناء والفحص وحدها (esbuild وweb-ext)، ولا اعتمادية تُشحن مع الإضافة.
- اختبارا التوافق مع `ffmpeg` يحتاجانه في المسار، كما في CI. ومحليًا بلا `ffmpeg` يُذكر التخطي باسمه في مخرج الفحص، وأي تخطٍّ في CI فشل.
- `scripts/run-tests.mjs` يعطي كل اختبار مهلة دقيقتين (`--timeout=<ms>` لغيرها)، فالمعلّق يفشل باسمه. واختبار `todo` يُذكر باسمه كالمتخطّى: الفاشل منه فشل، وأي `todo` في CI فشل.

## البناء

| الأمر | ما يفعله |
| --- | --- |
| `npm run build` | يبني نسخة Chromium (Chrome وEdge وBrave) في `dist`. |
| `npm run build:dev` | بناء التطوير: معرض المكوّنات وخطاف حزام الاختبارات الحية، و`version_name` ينتهي بـ`-dev`. لا يُنشر. |
| `npm run build:firefox` | يبني نسخة Firefox في `dist-firefox`، بالشيفرة نفسها وبيان Firefox. |
| `npm run package` | حزمة التثبيت الشخصي في `release/tarjuman-<الإصدار>`، وحزم المتاجر الثلاثة وحزمة المصدر وبصماتها في `release/store`، بعد تدقيقها. |

والتفصيل في [دليل الصيانة](maintenance.md) §٥: ما في كل حزمة، والتدقيق، وإعادة البناء من المصدر بالبايتات نفسها.

## التثبيت من الشيفرة

لتجربة الإصدار الذي في المستودع، ولـFirefox حتى يُنشر في متجره. ابنِ الحزم أولًا:

```bash
npm ci
npm run package
```

- **في Chrome وEdge وBrave:** انسخ `release/tarjuman-<الإصدار>` إلى مجلد ثابت لا تنقله، ثم افتح صفحة الإضافات (`chrome://extensions` أو `edge://extensions` أو `brave://extensions`)، وفعّل «وضع المطوّر»، واضغط «تحميل غير معبأ» واختر المجلد. المتصفح يشتق معرّف الإضافة من مسار المجلد، والمحفوظات مربوطة به.
- **في Firefox:** افتح `about:debugging#/runtime/this-firefox`، واضغط «تحميل إضافة مؤقتة» واختر `release/store/tarjuman-<الإصدار>-firefox.zip`. تُزال الإضافة المؤقتة عند إغلاق Firefox، فخذ نسخة احتياطية قبل الإغلاق.

ونسخة المتجر إضافة أخرى بمعرّف آخر، فلا ترى محفوظات النسخة المحلية. والنسخة الاحتياطية تنقلها ([دليل الاستخدام](user-guide.md) §١ و§٩).

## الفحوص

| الأمر | ما يفحصه |
| --- | --- |
| `npm run check:i18n` | تغطية التوطين: تطابق فهرسي العربية والإنجليزية مفتاحًا وقالبًا، ووجود كل مفتاح تستعمله الشيفرة، ولا نص عربي خارج الفهرس في واجهات المنتج. |
| `npm run check` | الفحص الثابت (الأذونات، ولا شيفرة بعيدة ولا `eval` ولا HTML نصي ولا اتصال غير معلن؛ وهو نصي يكشف الخطأ لا التمويه المتعمد)، والأسرار، وتغطية التوطين، والإشعارات، وتطابق `PRIVACY.md` مع مصدره، ومواد المتاجر، واختبارات الوحدة، والبناءان. |
| `npm run test:integration` | اختبارات التكامل بين الطبقات. |
| `node scripts/run-tests.mjs test/e2e/static test/e2e/regression` | e2e الثابت والانحدار بلا متصفح، ومنه تغليف حزمة مبنية وتدقيقها (`test/e2e/static/release.test.js`). |
| `npm run lint:firefox` | `web-ext lint` على بناء Firefox. |
| `npm run check:all` | `check` والتكامل وe2e و`lint:firefox` بالترتيب. ويشغّلها CI ([`.github/workflows/ci.yml`](../.github/workflows/ci.yml)) خطوةً خطوة في كل دفع إلى `main` و`tj/**`، وكل طلب دمج، وأسبوعيًا، ثم `npm run package` بعدها (و`check:all` نفسه لا يشغّل `package`). |

وللتطوير السريع `npm test` (الوحدة وحدها) و`npm run check:quick` (الفحص الثابت والوحدة).

## الاختبارات الحية

في `test/live` و`test/e2e/live` سكربتات تفتح متصفحات حقيقية (Brave وChrome وEdge وFirefox) بملف تعريف اختبار منفصل، وتعمل على يوتيوب الحقيقي أو صفحات الإضافة. لا تُشغَّل في CI، ولا تُستورد من اختبارات الوحدة (استيرادها يشغّلها).

- **بإذن صاحب المشروع قبل كل جولة:** ما سيُفتح، وعدد الاختبارات، والمدة التقريبية، وما يلزم من يده إن وُجد.
- **ملف تعريف منفصل خارج المستودع:** الافتراضي `~/Library/Application Support/Tarjuman-test/`، و`TJ_PROFILE_ROOT=<مجلد>` يعزل جولة بعينها في مجلد آخر.
- **بلا نافذة افتراضيًا**، و`--headed` يُظهرها. ووتيرة بشرية، ولا تسجيل دخول ولا إدخال كلمات مرور، ولا تحايل على أي تحدٍّ («لست روبوتًا» يوقف الجولة).
- **النتائج** في `test-results/live/<المجلد>` (متجاهَل في Git) أو حيث يشير `--out`، منقّاة من الروابط والرموز ومسارات الجهاز. ولا تُحفظ في المستودع.
- **الاستخراج لا يُؤتمت:** تحت أي تحكم يعيد يوتيوب جسم الترجمة فارغًا، فيمر الاستخراج الحقيقي بجلسة يدوية في نافذة عادية (`test/live/aa5/hand.mjs`)، والباقي آلي.

و«هل تغيّر يوتيوب؟» (`npm run youtube:shapes`) جولة حية كذلك، تقارن أشكالًا بلا قيم بخط أساس في المستودع؛ ومنطقها النقي في `scripts/youtube-shapes.mjs` تختبره اختبارات الوحدة دون متصفح.

وما يُشغَّل في الصيانة الدورية في [دليل الصيانة](maintenance.md) §٢ و§٣، وأدوات الحزام في [`test/live/harness`](../test/live/harness/README.md)، وسكربتات e2e الحية في [`test/e2e`](../test/e2e/README.md).

## هيكل المستودع

| المجلد | ما فيه |
| --- | --- |
| `src/manifest.json` | بيان Chromium، ومنه يُشتق بيان Firefox في `scripts/targets.mjs`. |
| `src/_locales` | اسم الإضافة ووصفها بالعربية والإنجليزية (`default_locale: en`)، وتتبع لغة المتصفح لا «لغة الواجهة». |
| `src/background` | العامل الخلفي: حفظ الملفات بواجهة التنزيلات، والكاتب الواحد للتخزين. |
| `src/content` و`src/main-world` | سكربتا المحتوى: المتحكم وجسر الصفحة، والتقاط نسخة رد الترجمة الذي طلبه المشغّل. |
| `src/extract` | استقبال الرد الملتقط وحفظه واختيار مسار الترجمة. |
| `src/player` | أزرار الشريط وقوائمه، والطبقة فوق الفيديو، ولوحة النص المتزامن. |
| `src/pages` | صفحات الإضافة: نافذة الأيقونة، والمحفوظات، والمحرّر، والإعدادات. |
| `src/core` | المنطق النقي بلا DOM: النموذج والتخزين، والتحويل إلى SRT، والاستيراد والتصدير والمقارنة والمحاذاة، والتحرير، والنسخ الاحتياطي، والبلاغ، والأخطاء. |
| `src/ui` | النظام البصري المشترك: الرموز والخطوط والشعار والأيقونات والمكوّنات، وتهيئة لغة الواجهة (`locale.js`). |
| `src/i18n` | نظام التوطين: `index.js` (`t` و`texts` و`lt`)، و`locale.js` (سياسة اللغة)، والفهرسان `ar` و`en` بالملفات نفسها. العربية هي النص المرجعي، وأي نص جديد يدخل الفهرسين معًا. |
| `src/dev` | حزام الاختبارات الحية، في بناء التطوير وحده. |
| `test` | الوحدة والتكامل وe2e والحية، والعيّنات (`test/fixtures` و`test/e2e/fixtures`) والمساعدات. |
| `scripts` | البناء وطبقة Firefox والفحوص والتغليف وتدقيق الحزم، ومولّد `PRIVACY.md`. |
| `store` | مواد المتاجر: النصوص والأيقونات والبلاطات واللقطات وإجابات نماذج التقديم وملاحظات المراجعين وملفا الاختبار. |
| `docs` | الوثائق، وفهرسها في [`docs/README.md`](README.md). |
| `tools/brand` | مولّد أيقونات الإضافة من مصدر الشعار، بلا متصفح. |
| `tools/calibrate-reading.mjs` | مولّد جدول [معايرة كثافة القراءة](reading-calibration.md). |
