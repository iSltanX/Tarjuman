## ما اختُبر

بناء الإنتاج (`npm run build`) بلا نافذة، بضغطات Input حقيقية، في ملف تعريف اختبار منفصل خارج المستودع، وفي صفحات الإضافة وحدها (لا يوتيوب ولا تسجيل دخول).

| الفحص | ما يثبته |
| --- | --- |
| `delete-active-stale` و`delete-active-after-refresh` | تأكيد «حذف الترجمة النشطة (1)؟» مفتوح، والتبويب الآخر يفعّل الترجمة 2 بواجهته: الموافقة لا تحذف شيئًا، ورسالة `PG_DELETE_STALE`، وتُعاد القائمة (2 نشطة). ثم «(2)؟» يحذف 2 وحدها. |
| `delete-card-stale` | حذف بطاقة 2 والتبويب الآخر يسمّيها: تبقى بمحتواها واسمها الجديد. |
| `delete-previous-stale` | حذف النسخة السابقة والتبويب الآخر يستعيدها: تبقى السابقة الجديدة. |
| `delete-all-stale` و`delete-all-after-refresh` | حذف كل البيانات والتبويب الآخر يسمّي ترجمة: يبقى الفيديو؛ ثم الحذف على الحال الجديدة يزيله. |
| `study-library-negative-offset` | إزاحة −2 ث: الإشعار (`role=note`) قبل التنزيل، والروابط `0، 4، 9` ث (كانت `1، 6، 11` قبل الإصلاح). |
| `study-library-positive-offset` | إزاحة +0.5 ث: لا إشعار، والروابط بالإزاحة. |
| `study-editor-negative-offset` | الحوار نفسه من المحرّر: الإشعار، والروابط `0، 4، 9`. |
| `fingerprint-new-timing-saved` و`fingerprint-upload-no-false-drift` | تصدير الإنجليزية بالنص نفسه وتوقيت آخر يحفظ بصمته الثانية بأزمنتها، ورفع الترجمة يُقارن بها: مطابقة ولا انحراف. |
| `report-focus-keyboard-retry` | Enter على «أعد المحاولة»: التركيز على منطقة النتيجة (`tabindex=-1`) أثناء الإرسال، ثم على «أعد المحاولة» الجديد بعد فشل ثانٍ، ثم على النتيجة بعد النجاح. لا يسقط إلى الصفحة. |
| `report-same-key-across-retries` و`report-next-report-new-key` | المفتاح نفسه في المحاولات الثلاث، ومفتاح جديد لبلاغ ثانٍ بالوصف نفسه بعد النجاح. |
| `report-copy-id-failure-visible` و`report-copy-id-success` | رفض الحافظة: «تعذّر نسخ الرقم…» بـ`role=alert` والرقم ظاهر والتركيز باقٍ على «نسخ الرقم»؛ والقبول: «نُسخ الرقم.». |
| `no-extension-errors` و`no-external-network` | صفر أخطاء للإضافة (عدا سجلي الشبكة للفشلين المقصودين في البلاغ)، وصفر طلبات خارجية. |

## ما استُبدل عمدًا ولماذا

- **خادم البلاغات:** محاكى بـCDP Fetch في صفحة الإعدادات نفسها. الطلبات الأربعة أُوقفت ورُدّ عليها من الحزام (انقطاع، و503، و201 مرتين). لم يُتابَع طلب إلى الشبكة ولم يُنشأ بلاغ حقيقي.
- **إذن مضيف البلاغات:** في نسخة الاختبار من `dist` داخل ملف التعريف (`host_permissions`)، و`chrome.permissions.request` مستبدل بـ«نعم» في الصفحة. حوار الإذن ينتظر يدًا بلا نافذة (T3)، وهو مما لم يتغيّر هنا.
- **الحافظة:** `navigator.clipboard.writeText` مستبدلة لتُرفض ثم تُقبل عمدًا.
- **صور الفيديو:** مطفأة في البذرة، فلا طلب إلى `i.ytimg.com` لمعرّفات اصطناعية.

## لم يُختبر

- حوار الإذن الحقيقي والإرسال إلى الخادم الحقيقي (أُثبتا في T3 وT8 ولم يتغيّرا).
- Edge وFirefox.
- حزم المتاجر: الحزم لم يُعَد بناؤها بعد هذه الإصلاحات.
