- **المشغّل:** `player-download` و`player-download-results` (السطران)، و`player-display-one` (بلا محدد) و`player-display-two` و`player-display-three`، و`player-confirm-second` («حفظ في»)، و`player-display-after-delete`، و`player-timing`، و`player-download-narrow`.

## لم يُتحقق هنا

- **حافظة الجهاز الفعلية:** بلا نافذة لا تصل الكتابة إليها، فالتحقق بالتقاط ما تكتبه الإضافة (عدد مرات الكتابة وطولها).
- **ملء الشاشة:** لم يُلتقط في هذه الجولة؛ مقاساته (320، صفوف 38) من الأنماط واختبارات الوحدة.
- **الاعتراض الحي من يوتيوب:** الجسم محقون؛ والاعتراض الحي الوحيد في الإصدار الثاني `test/e2e/live/v2/hand.mjs` بنقرات سلطان، وكان قبل الصقل (تدقيق 5fedcb9، GM-023).
- **تكبير المتصفح الفعلي:** فحصا `zoom125` و`zoom150` عرضان أضيق عند تكبير 100% لا تكبير حقيقي (GM-025).
- **قارئ شاشة حقيقي:** أسماء الوصول والأوصاف ومناطق `role=status` متحققة في الشيفرة واختبارات الوحدة، لا بقارئ شاشة.
