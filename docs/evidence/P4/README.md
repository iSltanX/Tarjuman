## سيناريوهات تصدير P3 الحقيقي

تعمل السيناريوهات السبعة تلقائيًا على `src/core/export` (بصمتها وملفاتها) حين تُدمج P3؛ وتُتخطى الآن بسبب غياب الوحدة في هذا الفرع. تحققتُ من سلامة المحوّل نفسه (توقيع `buildExport` والمخرجات) بوحدة تصدير مؤقتة مطابقة للعقد: 14 من 14، ثم حُذفت ولم تُلتزم. على المنسّق أن يرى هذه السيناريوهات تعمل (لا تُتخطى) بعد دمج P3 في فرع التكامل.

## المراجعة المستقلة

وكيل مراجعة بلا تعديل (جرّب نحو 90 مدخلًا عدائيًا): لا ثغرة أمنية مؤكدة، ولا ReDoS (أبطأ مدخل 5 م.ب: 395ms)، وقيود مدقق التقرير والسجل محققة. وجد ملاحظة مهمة واحدة وست ثانوية، **أعدتُ إنتاج الأربع الأولى بسكربت قبل الإصلاح** وأُصلحت كلها باختبار لكل منها:

| الملاحظة | الإصلاح |
| --- | --- |
| مجموع الأجزاء لا يُحدّ بـ50,000 فتعود `ok:true` بتقرير غير صالح | سقف تراكمي داخل حلقة القراءة (يحدّ الذاكرة أيضًا) |
| رأس مبتور أو بسهم مكسور أو بعلامة ALM عند أطراف الملف يُحذف بصمت «شرحًا» | سطر يشبه رأس مقطع عند الأطراف `IM_STRAY_TEXT` برقم السطر؛ وإضافة ALM وZWSP وWJ إلى العلامات غير المرئية |
| محارف تجاوز الاتجاه تبقى في النص؛ المقطع المحتوي ZWSP وحده لا يُعدّ فارغًا | تُزال بملاحظة؛ والفراغ البصري يشمل محارف التنسيق |
| الأرقام الهندية تُحسب حرفًا عربيًا فتخفي مقطعًا إنجليزيًا | `noArabic` يشترط حرفًا عربيًا فعليًا |
| رسالة `IM_BAD_NUMBER` تخفي الحد؛ تحذيرات الأجزاء بلا اسم ملف؛ اسم ملف بتجاوز اتجاه؛ قصّ يشطر زوجًا بديلًا؛ مسار `TJ_UNEXPECTED` بلا اختبار | رسالة بالحد؛ `params.file`؛ تنظيف وقصّ آمن؛ اختبار |

لم أعمل بالاقتراح: ثابت مشترك لحد رقم المقطع في `validate.js` (ملف مشترك مجمَّد)؛ بدله اختبار يربط حد المحلّل بمدقق النموذج.
