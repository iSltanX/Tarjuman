# أدلة P3 — التنزيل الحي (P3-AC3)

اختبار حي واحد لمعيار **P3-AC3**: الملف المسمّى بالمعرّف واللغة والنوع والوضع يُنزَّل محليًا عبر Blob على Brave وChrome. بقية المعايير (AC1 وAC2 وAC4 وAC5 وAC6) آلية، وأدلتها اختبارات الوحدة تحت `test/unit/extract` و`test/unit/convert` و`test/unit/export`.

## ما الذي يُختبر وكيف

- `live/download-check.mjs` يشغّل المتصفح بلا نافذة بملف اختبار جديد خارج المستودع (`Tarjuman-test/<المتصفح>-p3`)، ويحمّل `dist/` بالبروتوكول (`Extensions.loadUnpacked`)، ويفتح صفحة مشاهدة واحدة، ثم يحقن حزمة وحدات التصدير الحقيقية في العالم المعزول للإضافة.
- كل سيناريو يستدعي `buildExport` ثم `download` (Blob و`<a download>`) بنقرة مستخدم حقيقية (`userGesture`) على عينات P1 الحقيقية.
- يُنزَّل كل ملف إلى مجلد مؤقت (يُحذف بعد الانتهاء)، ثم تُقارَن **بايتات الملف على القرص** ببايتات ما يحسبه Node للمدخل نفسه، وتُقارَن أسماء الملفات بالمتوقعة.
- لا يُكتب ملف الدليل إلا بعد أن يمرّ على المنقّي (`findSecrets`) بلا اكتشاف: لا روابط ولا رموز ولا ملفات ارتباط. ويحوي النتائج والبصمات المختصرة وأحجام الملفات فقط، لا نص الترجمة.

```bash
command npm run build
command node docs/evidence/P3/live/download-check.mjs --browser brave
command node docs/evidence/P3/live/download-check.mjs --browser chrome
```

## ملاحظات يجب أن يعرفها من يقرأ الدليل

- **أجزاء التقسيم معلومة لا شرط.** الاختبار بلا نافذة لا يُظهر مربع «السماح بتنزيلات متعددة» الذي قد يطلبه Chrome عند تنزيل أكثر من ملف بنقرة واحدة؛ فنزول الأجزاء الأربعة هنا لا يثبت أنه سينزل دون سؤال في جلسة المستخدم الفعلية. يُنصح بتجربة بنقرة حقيقية في نافذة ظاهرة عند P6 أو P9.
- **ملف زائد في Chrome.** في سيناريو التقسيم المتباعد ظهر في مجلد التنزيل ملف مؤقت من المتصفح نفسه اسمه `downloads.html (1).crdownload`. ليس من تنزيلاتنا؛ فتنزيلات الأجزاء الأربعة كلها في حالة `completed` وبمطابقة بايتية. لم يُسقط الاختبار لأن السيناريو معلوماتي، ولم يظهر ملف زائد في سيناريوهات الشرط.
- **حقل `watchPage`.** المدة التي تسجّلها الخطوة `watch-page` تُقرأ من مشغّل الصفحة وقت الفحص، وقد تكون مدة إعلان (قيم مثل 6 أو 32 ثانية ظهرت في تشغيلات تجريبية) لا مدة الفيديو. غير مؤثرة في النتائج: العينات المصدّرة ثابتة من P1، والخطوة تشترط فقط جاهزية الصفحة والعالم المعزول.
- **لا حساب ولا تسجيل دخول.** الجلسة لحساب غير مسجَّل، ولم يُدخَل في الاختبار كلمة مرور ولا أُنشئ حساب.
