# أدلة AA3 — نافذة الإضافة والتعليمات، وواجهات اللغات

المعاينة البصرية المحلية (معيار AA3 في [`docs/aa-plan.md`](../../aa-plan.md)): نافذة الإضافة بحالاتها وحالات كتلة «تعليمات الترجمة»، وقسم «اللغات»، والزوج اللغوي في المحفوظات ورأس المحرّر، بالوضعين، **بلا يوتيوب ولا شبكة**، بإذن سلطان (2026-11-07).

| البند | القيمة |
| --- | --- |
| السكربت | [`test/live/aa3/preview.mjs`](../../../test/live/aa3/preview.mjs) |
| المتصفح | Brave (Chrome/157.0.8103.39) بلا نافذة، بملف تعريف اختبار جديد في مسودة الجلسة (`TJ_PROFILE_ROOT`) |
| الحزمة | بناء التطوير من `tj/aa-2.0.0` بعد قراري سلطان ق٨ وق٩ وإصلاحات المعاينة (الإصدار `1.1.0-dev`؛ الرقم يُرفع في AA5) |
| البيانات | عيّنة البذر في `test/live/ui/seed.mjs`، و«صور الفيديو في المحفوظات» أُطفئ بمفتاحه الحقيقي قبل فتحها |
| رد صفحة الفيديو | **محاكى**: النافذة تُفتح تبويبًا بحقن قبل تحميلها يجعل `chrome.tabs.query` يعيد تبويب يوتيوب مصنوعًا و`chrome.tabs.sendMessage` يعيد رد حالة مصنوعًا بصيغة `VideoStateReply` (بلا طلب ولا رسالة حقيقية)، والحافظة محاكاة بنجاح أو فشل |
| النتيجة | **16/16** في التشغيل الثاني: الحالات الإحدى عشرة بقيمها المتوقعة وبلا فيض أفقي عند 340، وقسم «اللغات»، والزوج في المحفوظات، والزوج والبحث في المحرّر، ولا طلب خارج الإضافة (0)، ولا خطأ من الإضافة (0)، و24 لقطة ([`brave/preview.json`](brave/preview.json)) |

**الحالات** (`brave/popup-*`، عرض 340، كلٌّ بالوضعين `-light` و`-dark`؛ والأرقام كلوحة 09):

| اللقطة | الحالة | المتوقع والمتحقق |
| --- | --- | --- |
| `popup-1-active` | ترجمة نشطة، والزوج مضبوط | «من» الإنجليزية مكتشفة، و«إلى» العربية، والزر مفعّل، و«تحرير الترجمة» مؤطّرًا في البطاقة |
| `popup-2-target-empty` | بلا ترجمة، و«إلى» غير مختارة | «من» اليابانية من المسار الملتقط، والزر معطّل بسببه |
| `popup-3-picker-open` | قائمة «إلى» مفتوحة | البحث، ثم «للوصول السريع» بالعربية والإنجليزية (ق٩)، ثم كل اللغات، ولكلٍّ اسمها الأصلي ورمزها |
| `popup-4-copied` | بعد النسخ (اليابانية ← الإنجليزية) | الزر «نُسخت التعليمات» بلون النجاح، وتحته الزوج، والخطوات بالزوج |
| `popup-5-not-video` | ليست صفحة فيديو | الكتلة بآخر زوج والنسخ معطّل بسببه (ق٨)، وآخر الترجمات بزوج كلٍّ منها |
| `popup-6-loading` | جارٍ القراءة | هيكل البطاقة والكتلة |
| `popup-7-error` | تعذّر ربط الأدوات وتعذّر النسخ | سطر الأدوات بسببه، والزر «تعذّر النسخ — أعد المحاولة» بلون الخطر، والتنبيه |
| `popup-A-nothing` | لا شيء مكتشف ولا «إلى» | «اختر لغة» في الحقلين والزر معطّل |
| `popup-D-rtl-source` | العربية ← الإنجليزية | أي اتجاه، والزر مفعّل |

والحالة B (الإنجليزية ← العربية) هي `popup-1-active`، والحالة C هي `popup-4-copied`، والحالة 8 (الداكن) هي لقطات `-dark` كلها.

**الصفحات:** `settings-langs` (قسم «اللغات»: الزوج الافتراضي «تلقائي من مسار الفيديو ⇄ العربية»، والتذكّر، واللغات الأخيرة بأسمائها بلغاتها، ولغة الواجهة، و«3 ترجمات في 3 فيديوهات» بلا لغة محددة)، و`library` (الزوج في كل صف)، و`editor` (الزوج في الرأس، والبحث «في الترجمة» و«في الأصل (قراءة فقط)»، وعمود المرجع باسم لغته)، بعرض 1280 و1440.

**ما أصلحه التشغيل الأول** (15/16، وسقوطه من السكربت: ضغطة فتح القائمة تتكرر لكل وضع فتغلقها): سطر اللغة في القائمة صار «الاسم الأصلي · الرمز» كلوحة 09، و«ترجمة العربية» صارت «ترجمة بالعربية»، ولا سطر مكرر تحت زر النسخ المتعذّر، ورأس المحرّر يعرض لغة الترجمة المحفوظة («لغة غير محددة» لما حُفظ قبل 2.0.0) كالمحفوظات بدل رمز اسم الملف.

**ما لا تغطيه:** صفحة يوتيوب الحقيقية (رد الصفحة محاكى هنا)، وشريط المشغّل وقوائمه (مختبرة آليًا في `test/unit/player/controls/` و`test/integration/player/`)، والحافظة الحقيقية (بلا نافذة لا تصل الكتابة إلى حافظة الجهاز)، وChrome وEdge وFirefox. والجولة الحية على يوتيوب في AA5.
