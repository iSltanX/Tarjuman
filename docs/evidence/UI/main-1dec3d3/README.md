- **فحص الإعدادات في الدخان:** كان يتوقع نص السعة «بلا حد ثابت» ظاهرًا في صفحة الإعدادات؛ وبعد إعادة التصميم يظهر قسم واحد. صار الفحص يفتح «التخزين» بجزء العنوان (`#storage`) قبل القراءة، فيختبر معها التنقّل. سقط في Chrome قبل الإصلاح (14/15) ونجح بعده.
- **Brave:** التشغيل الأول انقطع بمهلة `Page.enable` بعد صفحة المحفوظات (تعثّر في التحكم البعيد، لا خطأ من الإضافة)، فبقيت بياناته في ملف `brave-p2`؛ والثاني سقط فيه `popup-video-state` لذلك وحده، ونظّف الملف في آخره؛ والثالث 15/15، وهو المحفوظ هنا.
- **ما لم يُختبر حيًا هنا:** الاستخراج الحقيقي من يوتيوب («تحميل الترجمة» ثم «تنزيل SRT») والدورة الكاملة بعده؛ يحتاجان جلسة يدوية بنقرات سلطان في نافذة بلا تحكم ([`test/e2e/README.md`](../../../../test/e2e/README.md))، لأن يوتيوب يعيد جسم الترجمة فارغًا تحت أي تحكم. آخر دورة كاملة ناجحة في P9 على `tj-v1`، ولم تمسّ إعادة التصميم وحدات الاستخراج والتصدير والاستيراد.
