## ما تغيّر

| الموضع | التغيير |
| --- | --- |
| `src/core/report/payload.js` | الجسم بحقول العقد وحدها. المنتج `tarjuman` ثابت، و`locale: "ar"`، والأنواع `bug` و`suggestion` و`other`. والوصف من 1 إلى 2000 محرف بعد القص. والتشخيص ثلاثة حقول فقط: `browser` و`browser_version` و`build_target`، بأشكال ضيقة، وما خرج عنها `unknown`. و`test: true` من بناء التطوير وحده. والمعاينة صفوف من الجسم نفسه، والنسخ JSON منسَّق |
| `src/core/report/client.js` | **الطلب الوحيد للبلاغ:** `POST https://app-reports.isultantf.workers.dev/v1/reports` بعد إذن المضيف. وترويستان فقط: `Content-Type` و`Idempotency-Key` (UUID واحد لكل بلاغ يُعاد في محاولاته). و`credentials: 'omit'`، و`redirect: 'error'`، و`referrerPolicy: 'no-referrer'`، ومهلة 30 ثانية. وبلا إعادة تلقائية. وجدول الردود: 201 و200 نجاح، و400 و413 و415 بلا إعادة، و429 و5xx والمهلة والشبكة بإعادة. وطلب الإذن متزامن داخل الضغطة، وفي Firefox معه `data_collection: ["technicalAndInteraction"]` |
| `src/core/report/diagnostics.js` | المتصفح وإصداره من `getBrowserInfo` (Firefox) أو علامات `userAgentData` (Edge وChrome)، أو `navigator.brave` (Brave). والنظام والمعمارية من `runtime.getPlatformInfo`. وهدف البناء من عنوان الصفحة (`moz-extension:`)، فالشيفرة واحدة في الهدفين. وكل مصدر يتعثر يصير `unknown` |
| `src/pages/settings/report.js` | زر «الإبلاغ عن مشكلة» في «حول» يفتح النموذج: النوع، والوصف بعدّاد، والمعاينة كاملة، وذكر المضيف والإذن قبل الإرسال. والنجاح يعرض `#id` مع «نسخ الرقم». والفشل يعرض نصه، و«أعد المحاولة» لما يُعاد، و«انسخ البلاغ». والنسخ بلا شبكة. وما يشبه رمز جلسة أو ملف ارتباط أو توقيعًا (منقّي التشخيص الموجود) يمنع الإرسال والنسخ، والرابط العام وحده لا يمنع |
| البيان وطبقة Firefox | `optional_host_permissions: ["https://app-reports.isultantf.workers.dev/*"]` في الهدفين، وفي Firefox `data_collection_permissions.optional: ["technicalAndInteraction"]`. والأذونات الإلزامية كما هي (`storage` و`unlimitedStorage` و`downloads`)، والإذن الاختياري لا يغيّر تحذيرات التثبيت |
| `check-static.mjs` | أضيق استثناء: سطر الطلب وسطر طلب الإذن حرفيًا، والمضيف رابطًا، في `src/core/report/client.js` وحده. وإذن المضيف الاختياري حرفيًا في الهدفين |
| `audit.mjs` | المضيف وطلب الإذن في حزمة الإعدادات وحدها، وفيها طلب `fetch` واحد بغلافه المسمّى، ونمط الإذن في البيان وحده (فحص جديد `report-channel-settings-only`) |
| الوثائق | `PRIVACY_LINE`، وREADME، والمواصفة (§١، وجدول «لا يفعله»، وصف القرار «قناة البلاغات»)، والقيود (§٧)، ودليل الاستخدام (§٨ و«حول» والتدقيق). المعالجة والحفظ محليان، والبلاغ استثناء يرسله المستخدم بنفسه |
| `iSltanX/app-reports` | وسم `product:tarjuman` (‎#5C4434، «ترجمان — Tarjuman (browser extension) · iSltanX/Tarjuman»)، وصف في جدول Products. ولا تغيير آخر: الالتزام `0f05873` سطر واحد في README |

- **T3:**
