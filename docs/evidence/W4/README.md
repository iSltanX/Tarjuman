## حدود الإثبات (صريحة)

- **الالتقاط:** تحت الأتمتة يعيد يوتيوب جسم الترجمة فارغًا (P1)، فمُرِّر جسم P1 الحقيقي لهذا الفيديو إلى المستخرج عبر خطاف التطوير كما في P3 وP6. ما بعده (القائمة والتنزيل والبصمة) مسار المنتج نفسه.
- **الحافظة:** بديلة في العالم المعزول وصفحة المحفوظات (تقيس الطول والبصمة)، فلم تُكتب حافظة الجهاز. كتابة الحافظة الفعلية أثبتتها P7 حيًا.
- **المنزلق:** أول تشغيل سقط فيه فحصان لأن السكربت ضغط السهم الأيسر لإنقاص منزلق اتجاهه RTL (حيث يزيده)، فبقي الحجم 160% وعرضت الطبقة 53px = 160% بدقة. صُحّح السكربت ليختار السهم بحسب الاتجاه المحسوب، ثم 18/18. وأُعيدت الدورة مرة ثالثة لإخفاء عمود الإنجليزي قبل لقطة المحرّر، بالنتيجة نفسها.
- **Chrome:** لم يُشغَّل في البوابة (البروتوكول Brave)؛ المتصفحان معًا في P9.
- **ملاحظة بصرية:** في [`w4-editor-saved.png`](brave/w4-editor-saved.png) تغطي رسالة «حُفظ ✓» العابرة جزءًا من عنوان الفيديو في رأس المحرّر. لا يسقط معيار؛ مسجّلة لـP9.
