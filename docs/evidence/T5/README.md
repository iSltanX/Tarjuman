> **المرحلة:** T5 من [جولة النشر](../../store-release.md)، على الفرع `tj/store-release` (2026-11-04). لا نشر للموقع، ولا تغيير في سلوك الإضافة.

## ما قُرئ

- **قناة البلاغات:** README في `iSltanX/app-reports` عند `0f0587371f89` (2026-11-03). منه الوجهة: عامل Cloudflare، ثم مشكلة في مستودع خاص. ومنه الحدود: خمسة بلاغات لكل IP في الساعة، ومئة في اليوم، والبصمة المملّحة المؤقتة. ومنه أن لا حذف تلقائيًا، وأن الرقم المرجع الوحيد.
- **Mozilla:**
  - [Built-in data consent](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/) (آخر تحديث 2026-10-18): تعريف النقل وفئاته و`none`.
  - [Add-on Policies](https://extensionworkshop.com/documentation/publish/add-on-policies/) §6: الإعلان المطابق، ونقل نشاط التصفح ضمن الوظيفة الأساسية وحدها.
  - [Policies FAQ](https://extensionworkshop.com/documentation/publish/add-on-policies-faq/) (2025-08-04): النسخ الاحتياطي المحلي بأمر المستخدم جائز.
- **الروابط في السياسة:** سياسات Google وCloudflare وGitHub و`bysltan.com` أعادت 200 في 2026-11-04.

## الحكم على `required: ["none"]`

- **لا يطابق** سلوك بناء Firefox ما دامت صور المحفوظات مفعّلة افتراضيًا. فهي تنقل معرّفات الفيديوهات المحفوظة إلى `i.ytimg.com` دون موافقة.
- أقرب الفئات `browsingActivity`، والصور ليست الوظيفة الأساسية.
- والبلاغ مطابق: `optional: ["technicalAndInteraction"]` يُطلب بأمر المستخدم.
- الخيارات والتوصية في [`docs/site/README.md`](../../site/README.md)، وهي [قرار] في `store/README.md` §٥.

## الفحوص

| الفحص | النتيجة |
| --- | --- |
| `command npm run check:wave` | أخضر. الوحدة 1322/1322، منها 5 جديدة لمولّد الخصوصية وجداول الأدلة. والتكامل 42/42، و`web-ext lint` بلا أخطاء، والخطة سليمة. و`check` يفحص `PRIVACY.md` بـ`--check` |
| `node scripts/site/privacy.mjs --strict --check` | يفشل كما يجب: موضعا [قرار] باقيان، وتاريخ السريان غير مثبت |
| مسارات جداول الأدلة في النصوص الثلاثة | كلها موجودة (اختبار الوحدة) |
| الحافظة | لا `clipboard.read` ولا `readText` في `src/`، وكل `writeText` من زر نسخ |
| الصور | `thumb.js` يستورده `pages/library` وحده، فلا صور في نافذة الأيقونة ولا غيرها |

**لم يُختبر:** لا اختبار حي في T5. النصوص مأخوذة من الشيفرة وقياسات T3، ولم يتغير سلوك يلزم قياسه.
