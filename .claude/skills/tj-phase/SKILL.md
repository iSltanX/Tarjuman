# /tj-phase $0

المرحلة المطلوبة: **$0** (بالصيغة `P3`). الحاكم `CLAUDE.md`، ثم `docs/delivery/runbook.md`، ثم ملف المرحلة في `docs/phases/`، ثم ما يحيل إليه من `docs/product-spec.md` و`docs/contracts/`.

## الحالة كما قيست الآن

- المجلد: !`pwd`
- مجلد git ومجلده المشترك (يختلفان في worktree): !`git rev-parse --path-format=absolute --git-dir --git-common-dir`
- الفرع الحالي: !`git rev-parse --abbrev-ref HEAD`
- تغييرات غير ملتزمة: !`git status --porcelain`
- الـworktrees: !`git worktree list`
- وسوم الأساس: !`git tag -l 'tj-*/base'`
- بطاقة المرحلة: !`command node tools/plan/plan.mjs brief $0`

## ما تفعله

1. **اقرأ** `CLAUDE.md` (محمَّل)، ثم `docs/delivery/runbook.md` كاملًا (الأدوار، والملكية، واقتصاد الفحوص، والحفظ والدفع، والاختبارات الحية، وصيغة التقرير)، ثم ملف المرحلة كاملًا. إن لم تُطبع بطاقة المرحلة أعلاه أو طُبع خطأ فالمعرّف خاطئ: توقّف واطلب معرّفًا بصيغة `P3`.
2. **نفّذ «دور: جلسة مرحلة» في دليل التشغيل حرفيًا**، خطوة خطوة، بقيم البطاقة: `‹ID›` هو $0، و`‹WAVE›` موجتها، و`‹BRANCH›` فرعها المتوقع. سطر «الإجراء» في البطاقة اقتراح؛ كل شرط يُقاس بأمر تشغّله أنت، فما طُبع أعلاه سياق لا دليل. وسقوط شرط يوقف الجلسة بطباعة ما سقط وما يلزم.
3. **مكان العمل:** هذه الجلسة مأذونة بالعمل في worktree. إن لزم فأنشئه بـ`git worktree add` تحت `.claude/worktrees/` ثم ادخله بأداة `EnterWorktree` (بالمعامل `path`). لا تعمل على `main` أبدًا.
4. **النموذج:** إن كان نموذج الجلسة غير المقترح في البطاقة فاذكر ذلك لسلطان في سطر واحد وتابع.
5. **الاختبار الحي:** قبل فتح أي متصفح أو تطبيق، رسالة واحدة لسلطان بحسب «الاختبارات الحية»، وانتظر موافقته.
6. **التنفيذ في هذه الجلسة نفسها** دون تشغيل المراحل الأخرى أو تنسيق متعدد الوكلاء؛ وكيل فرعي صغير واحد لمهمة معزولة فقط إن لزم، ويُطلب تقريره بالعربية.
7. **الحفظ والدفع بعد كل مهمة** (القسم في دليل التشغيل): مهمة مكتملة ومتماسكة ← فحوصها ← مراجعة الفرق ← التزام بملفاتها بأسمائها ← `git push` لفرع المرحلة. لا تؤجّل الحفظ إلى النهاية، ولا التزام فارغ، ولا `push --force`. والعمل غير المكتمل يُحفظ بالتزام `$0: WIP — …` على الفرع، وليس تسليمًا. إن فشل فحص أو تعذّر الدفع فاذكر السبب ولا تعلن نجاحًا.
8. **عند التسليم:** حدّث كتلة `tj-status` (بأمر `command node tools/plan/plan.mjs set $0 …`) وسجل التنفيذ وتقرير التسليم، ثم `command node tools/plan/plan.mjs check --phase $0`، ثم الالتزام الأخير، ثم `git push` لفرع المرحلة، ثم اطبع التقرير بالعربية مع نتيجة الدفع **وتوقّف**. لا تبدأ مرحلة أخرى، ولا تدمج، ولا تدفع غير فرعك.
